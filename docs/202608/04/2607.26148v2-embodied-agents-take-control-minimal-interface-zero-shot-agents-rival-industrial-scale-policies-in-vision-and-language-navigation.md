## 摘要
自主具身智能体必须维持一个长周期的决策循环，涉及感知、行动、验证和自校正，跨越许多步骤。当前系统通过特定任务的工作流或具身策略来维持这一循环。然而，这些固定的工作流和策略在跨环境时灵活性有限，并且在执行出错时往往缺乏有效的恢复策略。我们发现，通用型智能体可以自行维持这一循环。我们将这种组织方式称为智能体具身控制：推理模型直接引导每一个动作，使推理与控制保持一致。以零样本导航作为受控测试平台，我们仅用单目RGB摄像头和离散动作装备了三个编程智能体框架。在默认努力水平下，复现的opus-5运行平均成功率为$70.7\pm3.5$%，而fable-5在最高努力水平下达到78%。当在原始动作之外提供训练好的路径点工具时，混合fable-5智能体在默认努力水平下达到$76.7\pm0.6$%的成功率，同时仅使用一半的环境步数和不到四分之一的墙钟时间。在所有消融实验中，模型选择主导性能变化。观察到的框架差异不大，强制路径点有助于较弱的模型，但可能阻碍更强的模型。尽管更长的视野、延迟和上下文增长仍然是持续自主性的障碍，但这些结果表明，通用型模型在没有导航策略的情况下已经能够实现具有竞争力的具身控制。

## Abstract
Autonomous embodied agents must sustain a long decision-making loop that involves perceiving, acting, verifying, and self-correcting over many steps. Current systems sustain this loop through task-specific workflows or embodied policies. However, these fixed workflows and policies offer limited flexibility across environments and often lack effective recovery strategies when execution goes wrong. We find that a general-purpose agent can instead sustain the loop on its own. We term this organization agentic embodied control: the reasoning model directly steers every action, keeping reasoning and control aligned. Using zero-shot navigation as a controlled testbed, we equip three coding-agent harnesses with only a monocular RGB camera and discrete actions. At default effort, replicated opus-5 runs average $70.7\pm3.5$% success, while fable-5 reaches 78% at maximum effort. When a trained waypoint tool is offered alongside primitives, the hybrid fable-5 agent reaches $76.7\pm0.6$% at default effort, using half the environment steps and under a quarter of the wall time. Across the ablations, model choice dominates performance variation. Observed harness differences are modest, and forced waypoints help weaker models but can hinder stronger ones. Although longer horizons, latency, and context growth remain barriers to sustained autonomy, these results show that a general-purpose model can already achieve competitive embodied control without a navigation policy.

## 1. 论文的核心问题与整体含义（研究动机和背景）

自主具身智能体（如家庭机器人）需要在长时间交互中进行感知、行动、验证和自校正的多步骤决策循环。目前维持这一循环主要有两种主流路径：

- **训练型策略**（trained policies）：端到端网络将观测映射为动作（如 NaVid、StreamVLN、Qwen-RobotNav 等工业级导航模型），其缺点是跨环境泛化能力有限，依赖大量导航训练数据。
- **零样本工作流**（zero-shot workflows）：将冻结的视觉语言模型嵌入人工编写的流程中（如 NavGPT、MapGPT、NavCoT、NavGemini 等），由人类作者固定感知、记忆、规划、验证等模块的调用顺序，缺乏灵活性且恢复策略有限。

近期出现的“双脑”系统（如 ABot-N1、InternVLA-N1）虽将慢速推理模型与训练好的动作专家耦合，但二者的交接方式仍为固定流程。换言之，**大多数现有系统的交互逻辑在模型之外被人为指定**，模型只是流程中的一个组件而非主导者。

论文的核心问题是：**能否让通用推理模型自身掌控具身交互循环？**作者将这一组织方式命名为**智能体具身控制（Agentic Embodied Control）**：推理模型直接引导每一个动作，保持推理与控制的一致（alignment），不依赖任何导航专用策略、地图、记忆或搜索机制。整体含义在于，前沿视觉语言模型日益具备多轮感知、空间推理、进度追踪和工具使用能力，原本需要导航专用脚手架提供的功能可能已内化于模型本身——通用模型或许已能充当具身控制的核心。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
论文用最小的诊断式设置来检验智能体具身控制：使用**非具身领域**的通用编码智能体框架（coding-agent harness）作为交互载体，赋予模型极简的感知—动作接口，由模型自行决定何时观察、如何行动、何时纠错、何时停止。选择编码框架是为了确保周边的交互逻辑并非为导航而工程化。

### 2.2 最小感知—动作接口（Minimal-Interface）
接口仅包含两个工具：

- **observe()**：返回一张 512×512 前视 RGB 帧（HFOV 90°），不推进环境。
- **step(actions)**：按序执行 Habitat 的四种离散动作原语——FORWARD（前进 0.25 m）、LEFT（左转 15°）、RIGHT（右转 15°）、STOP（终止回合）；步数预算 500 步；返回已执行的原语数和剩余预算，不返回图像或碰撞反馈。

此接口不提供**位姿、里程计、深度、全景、地图、路径点候选、碰撞反馈或任何模拟器特权信息**。模型必须通过调用 observe() 来观察动作的效果，并从单目观测历史中推断地标、进度、回访、动作效果和停止点。整个回合在新会话中进行，无跨回合状态。

### 2.3 三种编码智能体框架
- **mini-swe-agent**（开源）——极简 ReAct 循环，无上下文管理，每次调用重发完整线性历史（含每张图片）。
- **Claude Agent SDK**（闭源）——严格 MCP 配置，仅暴露工具桥接。
- **Codex CLI**（闭源）——OpenAI 本地编码智能体框架。

三个框架均非为导航设计，未添加导航专用规划器、地图或策略。

### 2.4 推理努力（Reasoning Effort）控制
在主板上所有运行使用厂商默认推理努力。在努力消融中，仅将八个模型—框架对提升至最大努力，其余不变。

### 2.5 混合接口（Hybrid Interface）
额外暴露一个训练好的路径点工具（RGB-D 深度预测器驱动的候选路径点），与原语动作并列，由模型在运行时自行决定使用哪种控制粒度。这是将专用模块从强制控制路径转变为可选能力的测试。

## 6. 论文的主要结论与发现

1. **最小接口的零样本智能体具身控制已达竞争力水平**：仅用单目 RGB + 四原语动作，opus-5 默认努力平均 70.7±3.5 SR，fable-5 最高达 78 SR，与工业级训练导航模型（Qwen-RobotNav 72 SR）相当甚至更优。

2. **模型选择主导性能变化**：同一循环和动作空间下，仅更换 VLM 模型跨越 5–72 SR 的最大范围；框架差异（1.7–7.3 SR）远小于模型差异；推理努力的影响因模型而异（−5 至 +9.7 SR 不等）。

3. **路径点接口的价值取决于模型能力与是否强制**：强制路径点对最弱模型增益达 37–38 SR（qwen3.5-4b 从 5 到 43），对最强模型几乎无增益（fable-5 仅 +0.7 至 +1.3）；在 VLNVerse 上方向逆转（下降 4–6 SR，碰撞率升 4–6 倍）。

4. **可选脚手架优于强制路径**：混合接口下 fable-5 默认努力达 76.7±0.6 SR，超过两种强制接口（68.3 与 69），且用一半步数、四分之一时间接近最大努力原语的 78 SR；智能体自发形成"粗到细"策略。

5. **失败是"沉默"且路线级而非停止级**：30 个失败中 26 个以主动 STOP 结束，23 个声称成功但距目标 3.1–34.1 米；仅 5 条轨迹进入 3 m 成功区域；至少 15 次推理中已表达正确怀疑但仍走向错误终点（自我诊断但不自我纠错）。

6. **长视野仍是不小挑战**：R2R-CE 上 70 SR 降至 RxR-CE 上 26 SR；上下文增长（RxR-CE 中位 49.2k tokens）和墙钟时间（中位 527 秒）构成部署壁垒。

7. **物理部署揭示"推理迁移但具身不迁移"**：逻辑推理、视觉锚定和条件导航大多有效，但缺乏身体意识（相机先于身体穿过门洞导致卡住）、运动反馈不可靠（90° 转角实际仅转 11°）、跨视角空间状态不持续（数柱子失败）。

## 7. 优点：方法与实验设计的亮点

1. **诊断式干净设置**：用编码智能体框架+极简接口作为"最小探针"，彻底剥离导航专用脚手架，将控制权归属问题操作化、可检验。

2. **"控制权"分类学清晰**：附录 F 提出按"控制权威"（policy / workflow / agentic）与"能力来源"（trained / zero-shot）两轴分类，并据此裁决现有系统（如 ABot-N1、InternVLA-N1 的固定交接被归为 workflow），极具方法论价值。

3. **单轴干预设计**：分别固定其余因素，沿模型、框架、接口三个轴做受控对比，准确定位性能来源，避免"混在一起改变"的常见混淆。

4. **失败审计极尽详尽**：30 个失败逐集重建、两轮独立审计（6 确认、17 细化机制、7 修订分类、0 推翻），并归纳为四类失败模式，为后续研究提供可操作的改进方向。

5. **混合接口的设计洞见**："强制 vs 可选"的能力放置方式之别优于"有无"之别，对具身系统设计具有普适意义。

6. **跨基准一致性验证**：同一冻结循环在 R2R-CE、VLNVerse、HM-EQA、RxR-CE 和物理机器人上运行，证明方法的通用性边界清晰可见。

7. **对人类基准的纳入**：提供同一 rand100 板上的人类测试结果（SR 94，SPL 80.8）作为性能上限参考。

## 8. 不足与局限

1. **评估基准规模有限**：主结果建立在 100 个 episode 的固定子集上，虽然与其他零样本系统共享，但总体样本量偏小，SR 的统计功效有限（SD 已达 3.5 个点）。

2. **对照公平性受限**：不同模型经由不同厂商 API 和订阅路径提供，服务版本漂移（尤其 Codex CLI 的 gpt-5.6）无法完全控制；训练型系统在完整 split 上评估，与 rand100 不可直接比较。

3. **无法排除预训练数据污染**：论文承认零样本仅表示无导航专用权重训练，不排除模型预训练语料包含 Matterport3D 等导航场景数据的可能性。

4. **路径点臂混淆因素**：同时改变动作空间和观测格式（12 视图全景→4 视图条带），无法将性能差异分离为"动作抽象"vs"观测变更"的贡献。

5. **长视野表现大幅退化**：RxR-CE 上 SR 跌至 26–39%，上下文无界增长和延迟问题未被解决，离"持续自主"仍有本质差距。

6. **物理实验定性为主**：31 个回合为手工设计而非随机采样，无自动成功标签和真实位姿，结果仅为描述性统计，不能作为性能估计。

7. **未达 Autonomous Embodied Agent 标准**：论文附录 E 明确定义了五系统级要求（连续多任务、持久场景状态、闭环监控恢复、资源有界自维护、安全适应升级），而当前探针均无法满足，仍需未来工作在选择性记忆、验证与自校正、身体感知方面推进。

8. **单一任务类型**：实验集中于导航（VLN）和问答（EQA），未覆盖操作（manipulation）等需要更丰富交互的具身任务，泛化性有待验证。
