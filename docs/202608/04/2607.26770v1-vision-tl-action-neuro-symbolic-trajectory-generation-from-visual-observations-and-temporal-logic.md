## 摘要
时序逻辑提供了一种组合语言，用于制定长视野机器人任务，但现有的时序逻辑条件轨迹生成器可以通过在任务图中编码精确的物体几何信息来回避感知到符号的绑定。我们提出了视觉-时序逻辑-动作方法，它从多视角图像、无坐标的时序逻辑语法图和机器人初始状态生成动作轨迹。时序逻辑节点标记和空间视觉标记通过双向交叉注意力融合，所得的表示用于条件化流匹配轨迹生成器。视觉标记仅增加归一化的图像平面位置和相机视角标识符，而仅在训练时使用的谓词到区域目标鼓励对参考物体的接地。与该领域的先前工作一致，我们使用成功率@K评估模型，即至少有一个K采样轨迹满足时序逻辑规范的任务比例。在Panda任务上，我们的模型达到67.45%的成功率@1024，而oracle状态基线为59.11%。在AntMaze任务上，它达到96.35%的成功率@256，与oracle结果96.88%相当。分辨率和干预研究表明，空间细节依赖于语义接地，谓词身份影响注意力和性能。这些结果表明，从视觉观察和结构化时序逻辑目标到动作轨迹存在直接映射，而推理时无需物体几何信息。代码可在https://github.com/AricLau07/vision-tl-action获取。

## Abstract
Temporal logic (TL) provides a compositional language for the formulation of long horizon robotic tasks, but existing TL-conditioned trajectory generators can sidestep perception-to-symbol binding by encoding exact object geometry in the task graph. We introduce \emph{Vision-TL-Action}, which generates action trajectories from multi-view images, a coordinate-free TL syntax graph, and the robot initial state. TL-node tokens and spatial visual tokens are fused through bidirectional cross-attention, and the resulting representation conditions a flow-matching trajectory generator. Visual tokens are augmented only with normalized image-plane locations and camera-view identifiers, while a training-only predicate-to-region objective encourages grounding to referenced objects. Consistent with prior work in this domain, we evaluate the model using Success@$K$, the fraction of tasks for which at least one of K sampled trajectories satisfies the TL specification. On Panda task, our model achieves 67.45% Success@1024, compared with 59.11% for the oracle-state baseline. On AntMaze task, it achieves 96.35% Success@256, comparable to the oracle result of 96.88%. Resolution and intervention studies show that spatial detail depends on semantic grounding and predicate identity affects both attention and performance. These results demonstrate a direct mapping from visual observations and structured TL goals to action trajectories without requiring object geometry at inference. Code is available at https://github.com/AricLau07/vision-tl-action.

## 2. 方法论与关键技术

**核心思想**：以坐标无关的TL语法图和多视角视觉观察为输入，通过双向交叉注意力融合TL节点token与空间视觉token，并引入训练时的谓词到对象接地监督，最后由流匹配轨迹生成器输出候选轨迹。

**关键技术细节**：

- **坐标无关TL图编码**：语法图节点特征保留算子类型、时间区间、谓词类型、对象身份嵌入（学到的连续嵌入）、形状类别和语法角色，但不含物体坐标和尺寸。对象身份仅用分类索引表示，映射为可学习的嵌入向量。
- **可寻址多视角视觉token**：共享视觉骨干网络独立处理每个视角图像，将特征图展平为局部特征序列；每个token附加归一化特征网格坐标(ξ, η)和视角坐标ν作为地址编码（采用零初始化线性投影，训练中学习），使token在扁平化后仍保留空间与视角信息。
- **图-视觉双向交叉注意力**：两层、每层四个注意力头；TL→视觉方向使得每个TL节点token从视觉token中检索场景证据；视觉→TL方向让视觉token根据更新后的TL节点token重新表征；交替迭代两次后，分别做masked mean池化（TL节点）和mean池化（视觉token），拼接后经投影得到融合特征fgv。
- **谓词-对象接地目标（训练时监督）**：对每个引用对象的原子谓词节点，计算其最终层TL→视觉注意力在目标对象投影区域token上的注意力质量，最大化该质量之和的对数作为辅助损失Lground；该监督仅在训练时使用，推理时不依赖任何几何投影。
- **流匹配轨迹生成**：采用TeLoGraF的流匹配Temporal U-Net主干；融合特征与初始状态嵌入拼接为条件向量，学习条件向量场vθ；训练目标为流匹配损失LFM加上加权的接地损失（L = LFM + λgLground），Panda中λg=0.003，AntMaze中λg=0.002；推理时通过ODE积分从高斯噪声演化到数据分布得到候选轨迹。

## 6. 主要结论与发现

- Panda任务：Vision-TL-Action的Success@1024达67.45%±1.63，超过oracle-state的59.11%±1.19（提升+8.33 pp，bootstrap区间[1.56, 15.36]）和视觉融合基线的62.76%（提升+4.69 pp，区间[1.56, 8.07]）；在AND/OR和until任务上提升最显著。

## 8. 不足与局限

- 训练仍需特权监督：接地目标依赖环境特定的物体投影到视觉token的映射，属于训练时的特权信息，并非完全无监督的视觉-符号对齐。
- 评估存在离线偏差：Success@K用真实几何计算STL鲁棒性做"best-of-K"覆盖评估，不是可部署的top-1选择机制，实际部署需额外的轨迹排名器。
- AntMaze使用合成语义栅格（map + targets）而非真实相机图像，与真实视觉感知仍有距离；Panda虽用渲染图像，也缺乏真实噪声、遮挡、光照变化。
- 单样本成功率明显低于oracle-state（尤其AntMaze，43.75%对61.46%），说明视觉条件的样本集中度不足，距直接部署还有较大差距。
- 固定迷宫、固定任务集和有限的机器人域（两个模拟域）限制了结论的泛化性；未在物理机器人上验证。
- 身份-颜色混淆问题曾对结果有显著干扰，说明模型对视觉外观的简单线索存在依赖；固定身份颜色虽大幅改善，但仍未建立完全的因果绑定机制（置换实验未恢复一致性）。
- 推理为开环一次性生成，无闭环重规划，未应对环境变化和动力学扰动。
- 算力报告不够完整：仅给出单机RTX 3090的推理耗时和显存占用，无GPU数量、总训练时长、总体能耗等。
- 部分消融（如Panda接口适配路径、AntMaze 4×4 vs 16×16的效应分离）是内部开发记录或混合了多个因素，需谨慎解读。
