## 摘要
长时程机器人操作要求策略跟踪已完成的子任务和关键交互事件。然而，现有的记忆机制严重依赖外部模型或预定义的更新规则。为了解决这个问题，我们提出了OnEvoMemory，一种用于预训练机器人策略的价值引导记忆模块。它维护近期上下文、高价值经验和显著转换，同时从轨迹结果中学习哪些经验应被保留。离线演示初始化记忆先验，而成功和失败的在线轨迹优化记忆选择，帮助策略识别任务阶段转换并避免重复已完成子任务。在长时程操作基准上的实验表明，OnEvoMemory通过离线初始化和在线记忆演化提升了基础VLA策略的性能。

## Abstract
Long-horizon robot manipulation requires policies to track completed subtasks and critical interaction events. However, existing memory mechanisms heavily rely on external models or predefined update rules. To address this, we propose OnEvoMemory, a value-guided memory module for pretrained robot policies. It maintains recent context, high-value experiences, and salient transitions, while learning which experiences should be retained from trajectory outcomes. Offline demonstrations initialize the memory prior, whereas successful and unsuccessful online rollouts refine memory selection, helping the policy recognize task-stage transitions and avoid repeating completed subtasks. Experiments on long-horizon manipulation benchmarks show that OnEvoMemory improves the performance of the base VLA policy through both offline initialization and online memory evolution.

- 长时程机器人操作（long-horizon manipulation）要求策略持续追踪已完成的子任务和关键交互事件（如成功抓住物体、丢失接触、进入新任务阶段等），以避免重复已完成的步骤或丢失任务进度。
- 现有记忆增强方法存在明显局限：
  - 一类方法依赖外部视觉语言模型（VLM）识别关键帧或选择历史信息，记忆选择器与底层策略脱节，无法基于在线交互结果进行持续适应；
  - 另一类方法采用固定时间窗口、相似性检索或手工设计的更新规则，预先决定了“什么信息值得保留”，难以根据任务需求和实际轨迹结果动态调整。
- 由此提出核心问题：**模型如何从轨迹结果中学习“什么值得记忆”？**
- 论文提出 **OnEvoMemory**，一种价值引导的记忆模块，通过离线演示初始化记忆先验，并通过在线机器人轨迹（成功与失败）不断演化记忆选择，最终在不修改预训练策略的前提下提升长时程任务表现。

## 2. 方法论
- **核心思想**：将记忆机制与预训练策略解耦——冻结基础 VLA 策略，仅学习记忆读取、写入和注入模块；利用动作条件价值估计器指导记忆的保留与更新。
- **记忆体系结构**（分层存储）：
  - **短期缓冲（Short-term Buffer, $M^S$）**：固定容量 FIFO 队列，保存最近的动作查询表示，提供当前局部上下文；
  - **精英经验库（Elite Bank, $M^E$）**：保留高价值状态-动作经验，如稳定抓取、成功完成的中间阶段；
  - **过渡库（Transition Bank, $M^T$）**：保存轨迹质量发生显著变化的事件，如任务进展、接触丢失、失败与恢复。
- **价值引导写入机制**：
  - 给定当前观测 $o_t$，基础策略输出动作查询表示 $Q_t = E_\theta(o_t)$；
  - 价值估计器 $F_\phi$ 输出 $(V_t, k_t, v_t)$，其中 $V_t$ 为轨迹结果对齐的写入分数，$k_t$ 和 $v_t$ 分别为检索键和存储表示；
  - 若 $V_t$ 高则写入精英库；若 $|V_t - V_{t-1}|$ 大则写入过渡库，从而无需固定窗口或手工事件规则。
- **读取与注意力注入**：
  - 检索时，每个长期记忆库返回语义最相关与最近写入的经验：$R_b^t = \text{TopK}_{\text{sim}}(Q_t, M_b^t) \cup \text{RecentK}(M_b^t)$；
  - 与短期缓冲整合为记忆上下文 $C_t$；
  - 通过门控交叉注意力更新当前查询：$\tilde{Q}_t = Q_t + g_t \cdot \text{MHA}(Q_t, C_t, C_t)$，再由基础动作解码器输出动作块。
- **离线初始化与在线演化**：
  - 离线阶段：按时间顺序回放专家演示，早期经验填充记忆库，后续观测读取累积记忆进行动作预测，联合训练记忆读取、写入、注入模块和价值估计器；
  - 在线阶段：收集成功和失败的机器人轨迹，用轨迹结果作为监督，仅更新价值估计器和记忆模块，保持预训练视觉语言主干和动作策略完全冻结，实现记忆选择的持续演化。

## 3. 实验设计
- **基座策略**：将 OnEvoMemory 实例化在 **QwenOFT** VLA 策略上（文中引用 [3,11]）。
- **基准与数据集**：
  - **LiberoLong-10**：包含 10 个长时程操作任务，报告平均成功率；
  - **RMBench**：选取其中两个长时程任务 **SwapBlocks** 和 **SwapT**。
- **对比设置**（3 种）：
  1. 原始基础策略（Base VLA）；
  2. 基础策略 + 离线初始化记忆（+ Offline）；
  3. 离线初始化 + 一轮在线记忆演化（+ Online）。
- **在线数据收集**：LiberoLong-10 每个任务收集 20 条 rollout 轨迹；RMBench 每个任务收集 10 条轨迹。在线过程中冻结 QwenOFT，仅更新价值估计器和记忆相关模块。

  - RMBench SwapT：Base VLA 0% → +Offline 8.0% → +Online 10.0%。

## 6. 主要结论与发现
- 离线初始化记忆可以从演示数据中建立有效的记忆先验，显著提升长时程任务成功率（如 LiberoLong-10 上 +2.4 个百分点）。
- 一轮在线记忆演化可进一步改进记忆选择，带来额外提升（LiberoLong-10 上再 +1.6 个百分点；RMBench 上也有小幅提高）。
- 记忆在任务阶段转换处尤其重要，保留已完成子任务的高价值经验有助于策略维持进度、避免重复已完成动作。
- 在线失败轨迹提供了纠错信号，可以修正价值估计和记忆写入策略，使其保留更具信息量的经验。
- 在策略完全冻结的情况下，仅更新记忆模块即可带来性能改善，验证了“记忆可独立于策略进化”的可行性。

## 7. 优点
- **方法创新性**：提出学习型价值引导记忆写入，不需要外部 VLM 或手工设定的事件规则，能从轨迹结果中自主学习“值得记忆的内容”。
- **灵活性**：分层记忆结构（短期/精英/过渡）覆盖了近期上下文、高价值经验与关键转换，兼顾局部与长期信息。
- **实用性**：在线演化只更新轻量价值估计与记忆模块，预训练策略保持冻结，避免了大模型微调的高成本和灾难性遗忘风险。
- **问题定位清晰**：针对“记忆选择如何与任务需求对齐”这一核心难点，提供了可行的解决思路。
