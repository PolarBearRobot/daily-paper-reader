## 摘要
最近的视觉-语言-动作（VLA）方法通过将其表示与3D场景几何对齐来提高泛化能力。然而，这些方法从根本上是指令无关的：表示均匀地对齐整个场景，忽略了语言指令指定的特定目标物体的3D几何。这导致在细粒度操作和目标遮挡任务上失败，这些任务的成功取决于对目标物体而非整个场景的准确3D理解。为了解决这个问题，我们提出了Mind-VLA，一种用于VLA模型的指令感知空间表示对齐方法。具体来说，Mind-VLA首先获取语言指令指定的目标物体，然后准备其目标物体三视图并提取相应的VAE和VGGT特征。最后，将VLA模型的潜在表示与这些特征对齐，以实现指令感知的3D理解。Mind-VLA在LIBERO上达到93.9%，在CALVIN上达到4.47，使用紧凑的345M参数主干。在具有目标遮挡的真实机器人任务中，Mind-VLA达到54%的平均成功率，在真实机器人比较中，比表现最好的指令无关方法高出32个百分点。代码将公开。

## Abstract
Recent Vision-Language-Action (VLA) methods improve generalization by aligning their representations with 3D scene geometry. However, these methods are fundamentally instruction-agnostic: the representations align the entire scene uniformly, neglecting the 3D geometry of the specific target object designated by the language instruction. This causes failures on fine-grained manipulation and target occlusion tasks, where success depends on accurate 3D understanding of the target object rather than the entire scene. To address this, we present Mind-VLA, an instruction-aware spatial representation alignment method for VLA models. Specifically, Mind-VLA first obtains the target object specified by the language instruction, then prepares its target-object tri-view and extracts the corresponding VAE and VGGT features. Finally, the latent representation of the VLA model is aligned with these features to enable instruction-aware 3D understanding. Mind-VLA reaches 93.9% on LIBERO and 4.47 on CALVIN with a compact 345M-parameter backbone. On real-robot tasks with target occlusion, Mind-VLA reaches 54% average success, outperforming the best-performing instruction-agnostic method in real-robot comparison by 32 percentage points. Code will be publicly available.

## 1. 核心问题与研究动机

现有 3D 感知 VLA 方法虽然通过对齐 3D 场景几何提升了泛化能力，但存在一个根本性缺陷——**指令无关（instruction-agnostic）**：

- 已有方法（如图1a、1b所示）要么将整个场景的3D信息作为额外输入，要么在训练时将VLA表示与整个场景的3D特征进行对齐；
- 无论语言指令指向哪个物体，3D监督都是均匀作用在整个场景上，**忽略了指令所指定目标物体的细粒度3D几何**；
- 这种场景级、均匀式的3D建模会导致三类失败：
  - 目标物体与附近物体外观相似时，难以区分；
  - 目标被部分遮挡时，模型对目标3D结构缺乏显式监督，可靠性下降；
  - 细粒度操作任务中，关键的3D信息是目标物体本身而非整个场景。

作者据此提出 **Mind-VLA**：将VLA模型的表示对齐到**由语言指令指定的目标物体**的3D特征上，实现真正**指令感知（instruction-aware）**的空间理解。

## 2. 方法论

### 2.1 核心思想

Mind-VLA 不对齐整个场景，而是先解析语言指令，定位指令所指的目标物体，然后利用该目标物体的三视图（tri-view）提取3D特征，作为训练时的监督信号，将VLA的潜在表示与这些目标物体专属的3D特征对齐。

### 2.2 模型结构

基础架构为 VLA 模型，包含：

- **输入**：两个RGB图像（主相机+腕部相机，224×224×3）、CLIP编码的语言指令、8维本体感受状态；
- **Transformer骨干**：处理输入 token 与三组可学习查询（scene queries、object queries、action queries）；
- **动作头**：扩散Transformer，预测未来 Ta 步的 7 维动作。

### 2.3 关键模块

**（1）目标物体三视图（Target-object Tri-view）**
- 对每个任务/目标物体，离线准备 top、front、side 三个正交视图；
- 仿真环境：从物体网格渲染正交投影；
- 真实机器人：每物体手持相机拍摄三个近似规范视角（无需标定或精确正交对齐）；
- 每个指令通过任务定义配对固定的目标三视图，因此推理时的视角变化或遮挡不影响监督。

**（2）三视图潜在预测（Tri-view Latent Prediction）**
- 用冻结的 Stable Diffusion VAE 将三视图编码为压缩48倍的潜在向量 Zₘ₍ℓ₎；
- 目标查询 token 通过小型 MLP 解码为预测潜在 Ẑₜ，训练损失为 MSE：

```
L_tri = (1/K) Σₜ ‖ Ẑₜ − Zₘ₍ℓ₎ ‖²
```

- 损失将**语言指令与对应物体几何**绑定。

**（3）多层级 VGGT 特征对齐（Multi-level Alignment with VGGT）**
- 用4个中间Transformer层的特征分别对齐 VGGT 的4个对应层；
- VGGT 特征来源为目标物体三视图（而非全场景）；
- 每个对齐对 j 使用余弦距离损失：

```
L_geo = (1/4K) Σₜ Σⱼ [ 1 − (ϕⱼ(h̄_{t,j})ᵀ gₘ₍ℓ₎,ⱼ) / (‖ϕⱼ(h̄_{t,j})‖‖gₘ₍ℓ₎,ⱼ‖) ]
```

**（4）总训练目标**

```
L_MindVLA = L_VLA + λ_tri·L_tri + λ_geo·L_geo
```

其中 L_VLA 包含动作损失 L_act（扩散噪声预测）、场景级RGB重建 L_obs 和密集2D运动预测 L_traj。

**推理时**：VAE、VGGT、所有辅助解码器全部移除，仅保留基础 RGB+语言+状态输入，部署开销可忽略。

## 8. 不足与局限

### 方法层面的局限（作者在 Sec. 6 承认）
- **目标物体词汇表受限**：每个目标物体需要一次性三视图准备（仿真中从网格渲染、真实中手持拍摄），无法零样本部署到任意未见物体；
- **单目标映射**：每条指令只映射一个目标物体，导致长程链式任务（LIBERO-Long）不如支持场景级建模的方法（DreamVLA 89.5% vs Mind-VLA 87.5%）；
- **长程多目标任务可能需要场景级与目标级建模的结合**，Mind-VLA 未覆盖这一设置。

### 实验覆盖的局限
- **真实机器人任务范围窄**：仅3类任务、2个目标物体、1个遮挡等级（~25%）；
- **未涉及更复杂的遮挡**（如严重遮挡、多物体互相遮挡、动态遮挡）；
- **未在更多真实平台验证**，单一 xArm 6 平台的结论外推性有限；
- **统计效力**：30次试验/条件的置信区间未被报告；
- **未提供训练成本细节**（时长、显存、迭代数），难以评估实际训练开销。

### 潜在偏差风险
- 三视图监督属于**特权信息（privileged supervision）**，在推理时不可用，依赖离线预先采集；
- 真实机器人的三视图用手持相机获取，与仿真中的正交渲染存在分布差异，文中未分析这种差异的影响；
- LIBERO/ CALVIN 等仿真基准与真实世界的 sim-to-real 差距未系统量化。

## 总结

Mind-VLA 通过将3D监督从场景级改为指令感知的目标物体级，用很小的代价（仅训练时辅助损失）显著增强了 VLA 模型在细粒度操作和遮挡场景下的3D理解，仿真性能匹配7B级模型，真实遮挡鲁棒性大幅领先基线。但其对每个物体进行离线三视图准备的假设限制了零样本泛化，且长程任务表现有待提升，是值得关注的权衡。
