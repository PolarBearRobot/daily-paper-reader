## 摘要
从人类视频中学习操作技能对于可扩展的机器人学习具有前景。然而，人类与机器人之间的具身差异使得这一任务具有挑战性。一个可行的解决方案是学习与具身无关的、以对象为中心的可操作affordance。在这项工作中，我们提出一个框架，利用自我中心的人类视频，结合最先进的3D运动恢复结构和手部网格重建，提取可操作的affordance，如视觉、抓取和轨迹affordance，明确编码了在哪里交互、如何抓取以及如何移动。我们构建了EgoAffordance，一个大规模数据集，包含20.4万个片段，带有560万视觉affordance和1160万抓取与轨迹affordance。在此基础上，我们引入了VLAff，一个基于大型视觉-语言模型的统一基础模型，学习所有可操作affordance之间的跨模态相关性。给定视觉观察和指令，VLAff生成视觉affordance热图、抓取姿态和轨迹，然后利用3D场景信息将其转换为可直接执行的动作。通过大量实验，我们证明了VLAff不仅在视觉affordance预测上达到了最先进的性能，而且能有效应用于真实机器人应用，如零样本操作和affordance引导的机器人学习。

## Abstract
Learning manipulation skills from human videos is promising for scalable robot learning. However, the embodiment mismatch between humans and robots makes this challenging. One promising solution is to learn object-centric actionable affordances that are embodiment-agnostic. In this work, we propose a framework that leverages egocentric human videos with state-of-the-art 3D Structure-from-Motion and hand mesh reconstruction to extract actionable affordances such as visual, grasp, and trajectory affordances that explicitly encode where to interact, how to grasp, and how to move. We construct EgoAffordance, a large-scale dataset comprising 204K episodes with 5.6M visual affordances and 11.6M grasp and trajectory affordances. Building on this, we introduce VLAff, a large vision-language model-based unified foundation model that learns cross-modal correlations across all actionable affordances. Given a visual observation and instruction, VLAff generates visual affordance heatmaps, grasp poses, and trajectories, which are then converted into directly executable actions by utilizing 3D scene information. Through extensive experiments, we demonstrate that VLAff not only achieves state-of-the-art performance on visual affordance prediction, but can also be effectively applied to real robot applications such as zero-shot manipulation and affordance-guided robot learning.

## 1. 论文的核心问题与整体含义

- **研究动机**：从人类视频中学习机器人操作技能是构建可扩展机器人策略的重要途径，但人类与机器人的**具身差异**（embodiment mismatch）导致直接迁移困难。现有方法或只捕捉隐式表示（难以解释、难以转化为动作），或仅关注单一 affordance 模态（如只预测接触热图、手部姿态或轨迹），缺乏统一、可直接执行的动作表征。
- **核心问题**：如何从大规模第一人称（egocentric）人类视频中提取**与具身无关的、以对象为中心的可操作 affordance（actionable affordances）**，并训练一个统一模型，使其能够同时预测“在哪里交互（视觉）、如何抓取（抓取姿态）、如何移动（轨迹）”，从而支持真实机器人操作。
- **整体含义**：该工作提出了一套“数据构建—统一建模—下游应用”的完整方案，证明了统一的可操作 affordance 表征可作为连接人类演示与机器人控制的桥梁，为减少机器人数据采集成本、提升跨具身泛化能力提供了新思路。

## 2. 论文提出的方法论

- **核心思想**：将操作信息显式解码为三类互补的、与具身无关的 affordance：
  - **视觉 affordance（Av）**：交互区域的热图；
  - **抓取 affordance（Ag）**：96 维 MANO 手部参数（腕部旋转 + 15 个关节的 6D 旋转表示）；
  - **轨迹 affordance（At）**：交互后手部的 6D 位姿序列（平移 + 旋转）。
- **数据构建流程（EgoAffordance）**：
  1. 对自我中心视频进行语言描述与时间标注预处理，采样接触关键帧；
  2. 使用手-物检测器、分割模型、2D 手部关键点检测和跟踪，获取接触区域与物体掩码；
  3. 用 MANO 参数重建 3D 手部姿态，并通过自我分割 + 图像修复去除自我身体/手部干扰；
  4. 采用单目深度估计、相机内参估计、SLAM（DROID-SLAM）进行 3D 场景重建与手部轨迹跟踪；
  5. 最终将抓取姿态与轨迹相对于视觉 affordance 峰值点的 3D 投影锚点进行**空间变换**，得到对象中心的 affordance 表示。
- **统一模型 VLAff**：
  - 基于预训练 VLM（Qwen2.5-VL），并引入三类特殊 token：`<SEG>`（视觉）、`<GRASP>`（抓取）、`<p*>`（轨迹离散 token）；
  - 额外集成 **DINOv2** 视觉编码器以增强细粒度空间理解；
  - 视觉 affordance 解码器融合 DINOv2 特征与 `<SEG>` token 生成热图；
  - 抓取解码器将 `<GRASP>` token 映射为 MANO 参数；
  - 轨迹采用**空间分箱（spatial binning）**离散化为 token 序列，以自回归方式生成。
- **训练目标**：总损失 = λv·Soft Dice Loss（视觉热图） + λg·Smooth L1 Loss（抓取参数） + λt·Cross-Entropy Loss（轨迹 token）。
- **推理优化**：
  - **上下文轨迹引导（In-Context Trajectory Guidance）**：调用 GPT 等 VLM 生成粗粒度 3D 方向向量，用于约束初始轨迹 token 的采样；
  - **基于采样的轨迹选择**：采样 K 个候选轨迹，结合体素碰撞检测与方向对齐目标选出最优轨迹。
