## 摘要
从人类视频中学习操作技能对于可扩展机器人学习具有前景。然而，人类与机器人之间的具身差异使得这一任务具有挑战性。一个有前景的解决方案是学习与具身无关的以物体为中心的可操作可供性。在这项工作中，我们提出了一个框架，利用以自我为中心的人类视频，结合最先进的3D运动恢复结构和手部网格重建，来提取可操作可供性，如视觉可供性、抓取可供性和轨迹可供性，这些可供性明确编码了在哪里交互、如何抓取以及如何移动。我们构建了EgoAffordance，一个大规模数据集，包含204K个片段，带有5.6M视觉可供性和11.6M抓取与轨迹可供性。在此基础上，我们引入了VLAff，一个基于大型视觉-语言模型的统一基础模型，学习所有可操作可供性之间的跨模态相关性。给定视觉观察和指令，VLAff生成视觉可供性热图、抓取姿态和轨迹，然后利用3D场景信息将其转换为可直接执行的动作。通过大量实验，我们证明了VLAff不仅在视觉可供性预测上达到了最先进的性能，而且可以有效应用于真实机器人应用，如零样本操作和可供性引导的机器人学习。

## Abstract
Learning manipulation skills from human videos is promising for scalable robot learning. However, the embodiment mismatch between humans and robots makes this challenging. One promising solution is to learn object-centric actionable affordances that are embodiment-agnostic. In this work, we propose a framework that leverages egocentric human videos with state-of-the-art 3D Structure-from-Motion and hand mesh reconstruction to extract actionable affordances such as visual, grasp, and trajectory affordances that explicitly encode where to interact, how to grasp, and how to move. We construct EgoAffordance, a large-scale dataset comprising 204K episodes with 5.6M visual affordances and 11.6M grasp and trajectory affordances. Building on this, we introduce VLAff, a large vision-language model-based unified foundation model that learns cross-modal correlations across all actionable affordances. Given a visual observation and instruction, VLAff generates visual affordance heatmaps, grasp poses, and trajectories, which are then converted into directly executable actions by utilizing 3D scene information. Through extensive experiments, we demonstrate that VLAff not only achieves state-of-the-art performance on visual affordance prediction, but can also be effectively applied to real robot applications such as zero-shot manipulation and affordance-guided robot learning.

- **研究动机**：从人类视频中学习机器人操作技能具有可扩展性，但人类与机器人的**具身差异（embodiment mismatch）** 使直接迁移困难。传统机器人模仿学习需要昂贵且稀少的机器人状态-动作数据，而人类视频数据丰富易得，却缺乏显式动作标签、且存在形态差异。
- **核心问题**：如何从人类视频中提取**与具身无关（embodiment-agnostic）的可操作可供性（actionable affordances）**，使其既能编码丰富操作语义，又能直接迁移到机器人执行。
- **整体含义**：本文提出将可供性细分为三类互补的信息——**视觉可供性（在哪里交互）**、**抓取可供性（如何抓取）**、**轨迹可供性（如何移动）**，并训练一个统一的大视觉-语言模型（VLAff）联合预测三者，从而弥合人类演示与机器人执行之间的鸿沟。

## 2. 方法论：核心思想、技术细节与流程

- **核心思想**：从大规模第一视角（egocentric）人类视频中，利用计算机视觉技术自动提取三种可操作可供性，并构建统一的视觉-语言-可供性基础模型，以端到端方式联合预测视觉热图、抓取姿态和运动轨迹。

- **可供性提取管线**（从人类视频构建数据集）：
  1. 对每段带语言描述的视频，用大VLM提取接触关键帧、动作标签、物体类别、交互手信息。
  2. 用手-物检测器、分割模型、2D手部关键点提取器，识别接触区域并跟踪。
  3. 使用MANO参数重建3D手部姿态，并对自我视角进行分割和inpainting以减少视觉偏差。
  4. 通过单目深度估计、相机位姿估计（SfM）和3D手部轨迹跟踪，恢复3D场景和手部运动轨迹。

- **VLAff模型架构**：
  - 基于Qwen2.5-VL作为基础VLM，并额外引入DINOv2视觉编码器以增强细粒度空间特征。
  - 在VLM词典中新增三种特殊token：
    - `<SEG>`：通过分割解码器生成视觉affordance热图 `A_v ∈ R^{H×W}`；
    - `<GRASP>`：通过抓取解码器输出96维MANO手部参数 `A_g ∈ R^{96}`（全局手腕旋转 + 15个关节旋转，采用6D旋转表示）；
    - 轨迹tokens `<p_0>...<p_{N-1}>`：将6自由度位姿空间离散化为token序列，以自回归方式生成轨迹 `A_t ∈ R^{T×6}`。

- **训练目标**：
  - 视觉热图：Soft Dice Loss，处理热图不平衡；
  - 抓取姿态：Smooth L1 Loss；
  - 轨迹token：交叉熵损失；
  - 总损失为三者加权和。

- **推理策略**：
  - **In-context trajectory guidance**：利用GPT等大VLM提供3D方向向量（如`[0,0,1]`表示向前推），约束首个轨迹token的采样分布，使轨迹符合高层任务语义。
  - **Sampling-based trajectory selection**：采样K个候选轨迹，使用体素化碰撞检测和方向对齐目标，选出物理上更合理的轨迹。

## 6. 主要结论与发现

- VLAff在视觉affordance预测上达到**SOTA**，尤其是细粒度定位能力优于其他方法。
- 零样本操作：
  - 仿真环境中VLAff平均成功率83.0%，略低于VidBot（85.0%），但处于同一水平；VidBot依赖深度输入，在仿真中占优；

- Affordance引导的强化学习中，**视觉affordance热图是最关键的信息**，去掉后任务完全无法学习；抓取姿态贡献较小，归因于人手与机器人夹爪的形态差异。

## 7. 优点

- **统一建模**：首次将视觉、抓取、轨迹三种可供性纳入同一VLM框架，显式建模跨模态关联，而非独立处理。
- **数据规模化**：构建了大规模、多样化、带多模态标注的第一视角可供性数据集，且提取过程自动化。
- **实用性验证**：在真实机器人上进行了零样本操作和强化学习引导，证明了方法的可部署性。
- **推理策略有创新**：利用VLM的语义推理能力做方向引导，结合碰撞检测采样，提高轨迹物理合理性。
- **消融实验有洞察**：揭示各affordance的相对重要性，为后续研究提供指导。
