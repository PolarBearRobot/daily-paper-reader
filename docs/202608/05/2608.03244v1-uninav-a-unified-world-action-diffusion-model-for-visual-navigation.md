## 摘要
图像目标视觉导航是具身智能体的基本能力。现有导航策略能高效预测航点轨迹，但缺乏视觉预见性；而导航世界模型虽能预测未来观测，但通常需要昂贵的规划展开。我们提出UniNav，一个统一的世界-动作模型，通过单一扩散过程生成未来视觉观测和连续航点轨迹。给定历史帧和目标图像，UniNav在单个Transformer内联合去噪视觉和航点token，在共享框架中统一未来预测和动作生成。为了改善空间接地，我们融入了几何感知的相机token。我们还同时在带轨迹标签的导航数据和纯视频数据上训练，使模型能够从无需航点标注的多样视频中获益。基于该统一框架，我们引入两个变体：UniNav-Full联合预测可解释的未来观测及其对应轨迹，而UniNav-Fast在推理时移除未来图像token以实现高效轨迹预测。在导航基准测试上的实验表明，UniNav在所有数据集上的ATE均优于最强基线。通过单步推理，UniNav-Fast在不明显损失精度的情况下实现了0.1秒的延迟。代码将公开。

## Abstract
Image-goal visual navigation is a fundamental capability for embodied agents. Existing navigation policies efficiently predict waypoint trajectories but lack visual foresight, while navigation world models can anticipate future observations but often require costly planning rollouts. We present UniNav, a unified world-action model that generates future visual observations and continuous waypoint trajectories through a single diffusion process. Given history frames and a goal image, UniNav jointly denoises visual and waypoint tokens within a single transformer, unifying future prediction and action generation in a shared framework. To improve spatial grounding, we incorporate geometry-aware camera tokens. We also train on both trajectory-labeled navigation data and video-only data, enabling the model to benefit from diverse videos without waypoint annotations. Based on this unified framework, we introduce two variants: UniNav-Full jointly predicts interpretable future observations and their corresponding trajectories, while UniNav-Fast removes future-image tokens at inference for efficient trajectory prediction. Experiments on navigation benchmarks show that UniNav outperforms the strongest baseline in ATE across all datasets. With one-step inference, UniNav-Fast achieves a latency of 0.1s without a substantial accuracy drop. Code will be released.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**核心思想：**
- 将未来视觉观测、连续航点轨迹和相机几何信息统一为异质 token 序列，在一个共享的预训练视频扩散 Transformer 中联合去噪，实现"世界建模"与"动作生成"的统一。
- 引入几何感知的相机 token，将 3D 结构信息注入共享表征，强化空间接地。
- 支持混合训练：同时利用带轨迹标签的导航数据和纯视频数据（无需航点标注）。
- 提供两种变体：UniNav-Full（完整联合预测）和 UniNav-Fast（推理时移除图像 token，高效动作预测）。

**关键技术细节：**

1. **几何感知 token 表征（Geometry-Aware Token Representation）**
   - **视觉 token**：历史帧、未来帧、目标图像由冻结的视频 VAE（Wan2.1）编码并 patchify 为时空潜变量 token。
   - **航点 token**：K 步局部轨迹通过 MLP 投影到 Transformer 隐藏空间：
     \[
     h_{\text{traj},k} = \text{MLP}_{\text{traj}}(z_{\text{traj},k})
     \]
   - **相机 token**：用冻结的几何基础模型（DA3 / Depth Anything 3）提取未来视角的相机感知目标 token：
     \[
     x_{\text{cam},t+1:t+K} = \text{Norm}(G_\xi([o_{t-C+1:t}, o_{t+1:t+K}])_{t+1:t+K})
     \]
   - **统一 token 序列顺序**：
     \[
     [h_{\text{cam}} \mid h_{\text{pred}} \mid h_{\text{traj}} \mid h_{\text{hist}} \mid h_{\text{goal}} \mid h_{\text{reg}}]
     \]
   - 引入可学习的 register token 促进跨模态全局信息交换；视觉 token 保留旋转位置编码，非视觉 token 使用恒等位置编码。

2. **统一流匹配目标（Unified Flow-Matching Objective）**
   - 对三种模态（视频、轨迹、相机）采用统一的流匹配框架。设 \(x_m\) 为干净目标、\(\epsilon_m\) 为高斯噪声、\(\sigma_m\) 为噪声水平：
     \[
     z_m = (1 - \sigma_m)x_m + \sigma_m\epsilon_m, \quad u_m = \epsilon_m - x_m
     \]
   - 三个损失项：
     - **视频损失**：\(L_{\text{vid}} = \|v_{\theta,\text{vid}}(z,\sigma) - u_{\text{vid}}\|_2^2\)
     - **轨迹损失**：基于 SmoothL1 的逐航点速度回归：
       \[
       L_{\text{traj}} = \sum_{k=1}^{K} \sum_{d=1}^{3} \text{SmoothL1}(v_{\theta,\text{traj},k,d}(z,\sigma), u_{\text{traj},k,d})
       \]
     - **相机损失**：\(L_{\text{cam}} = \|v_{\theta,\text{cam}}(z,\sigma) - u_{\text{cam}}\|_2^2\)
   - **总目标**：
     \[
     L = \lambda_{\text{vid}} m_{\text{vid}} L_{\text{vid}} + \lambda_{\text{traj}} m_{\text{traj}} L_{\text{traj}} + \lambda_{\text{cam}} m_{\text{cam}} L_{\text{cam}}
     \]
   - 对于纯视频数据，设置 \(m_{\text{traj}} = 0\)，仅优化视频和相机损失。

3. **两个模型变体**
   - **UniNav-Full**：完整 token 序列参与联合去噪，迭代生成未来视频和航点轨迹，提供可解释的视觉预见。
   - **UniNav-Fast**：训练时使用**非对称注意力掩码**，阻止非未来 token 关注含噪的未来视频 token（但未来视频 token 仍可关注其他 token），使轨迹去噪不依赖未来视频表征；推理时直接丢弃未来视频 token，只采样航点轨迹，避免视频去噪和 VAE 解码，显著降低延迟。

**算法流程（推理时）：**
- 从随机噪声初始化未来图像 token 和轨迹 token；
- 以历史帧和目标图像为条件，迭代去噪（默认 2 步）获得航点轨迹（以及完整版中的未来观测）。

## 6. 论文的主要结论与发现

- **联合建模优于单独预测**：将未来视觉动态与航点动作联合建模，在 4 个真实世界基准上均取得最优 ATE（相比最强基线降幅 3.7%–24.7%），证明视觉预见有助于提升轨迹预测精度。
- **几何监督有效**：相机 token 去噪（非 oracle 设置）相比无几何信息模型在 RECON 上 ATE 从 0.321 降至 0.314；干净相机 token 条件（oracle）进一步降至 0.299，验证了未来视角几何信息的价值。
- **视频-only 数据需要几何桥接**：没有相机 token 去噪时，加入视频-only 数据反而损害性能（ATE +0.009）；启用相机 token 去噪后，视频-only 数据带来一致提升（ATE -0.012），说明几何监督是打通视觉动态与导航动作的关键桥梁。
- **高效推理可行**：UniNav-Fast 单步推理延迟仅 0.109s，精度几乎无损（ATE 仅从 0.314 升至 0.318），显著优于需要约 900s 延迟的 NWM（50 步 rollout）。
