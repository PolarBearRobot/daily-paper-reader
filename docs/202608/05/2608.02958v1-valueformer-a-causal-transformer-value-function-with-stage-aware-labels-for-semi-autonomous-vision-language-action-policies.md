## 摘要
视觉-语言-动作（VLA）策略通过行为克隆训练时会无声地失败：仅从动作流来看，崩溃的 rollout 看起来与平稳进展的 rollout 非常相似，因为模仿不提供进展的概念。强化学习可以提供这种概念，但在这里不切实际，因为真实机器人经验成本高昂，且可变形食物难以模拟。廉价的替代方案——终端成功/失败位——原则上可学习，但太过稀疏，无法指出 rollout 何时出错。我们认为，每帧标签而非架构才是难点：要有用，它必须是密集、连续且形状正确的。我们提出了 ValueFormer，一个基于冻结 DINOv3 骨干网络的紧凑型、策略无关的因果 Transformer，在一次前向传播中输出两个每帧信号：用于优势估计的平滑蒙特卡洛价值 V_mc，以及用于在线错误检测的尖锐二值价值，这两个目标在设计上方向相反。失败的情节使用阶段感知的成功-然后-衰减回报来标记，该回报保留失败阶段之前的成功曲线，检测则从错误区间而非单个失败时刻进行监督，因此策略能够从中恢复的错误也携带信号。在一个真实机器人双臂三明治装配任务（1,427 个情节）中，由评论家导出的每帧训练权重将任务完成率从 70% 提升到 85%（在 n=20 时处于噪声范围内），而批量 bf16 编码器将实时服务成本降低了 3~5 倍，使得评论家能在单个 GPU 上以 2 Hz 的频率与策略并行运行。

## Abstract
Vision-Language-Action (VLA) policies trained by behavior cloning fail silently: from the action stream alone, a collapsing rollout looks much like one making clean progress, because imitation supplies no notion of progress. Reinforcement learning would supply one, but it is impractical here, where real-robot experience is costly and deformable food resists simulation. The cheap alternative, a terminal success / failure bit, is learnable in principle yet far too sparse to say when a rollout went wrong. We argue that the per-frame label, not the architecture, is the hard part: to be useful it must be dense, continuous, and correctly shaped. We present ValueFormer, a compact policy-agnostic causal transformer over a frozen DINOv3 backbone that emits two per-frame signals in one forward pass: a smooth Monte Carlo value, V_mc, for advantage estimation and a sharp binary value for online mistake detection, targets that pull in opposite directions by design. Failed episodes are labeled with a stage-aware, success-then-decay return that preserves the success curve before the failure stage, and detection is supervised from mistake intervals rather than a single failure time, so mistakes the policy recovers from also carry signal. On a real-robot bimanual sandwich-assembly task 1,427 episodes), a critic-derived per-frame training weight lifts task completion from 70% to 85% (within noise at n=20), and a batched bf16 encoder cuts the live serving cost 3~5 times so the critic runs at 2 Hz alongside the policy on a single GPU.

- **核心问题**：视觉-语言-动作（VLA）策略通过行为克隆训练时存在“无声失败”问题——从动作流本身难以区分策略是否正在走向崩溃，因为模仿学习不提供任何进展（progress）的概念。

  1. **密集**（逐帧提供）；
  2. **连续**（平滑反映进展程度）；
  3. **形状正确**（target 的曲线形态符合任务结构）。
- **整体含义**：该论文并非提出一个新的策略架构，而是通过设计一种紧凑、策略无关的批评器（critic），为 VLA 策略的可靠部署提供廉价的每帧进度信号，从而实现半自主运行时的错误检测与训练加权。

## 2. 论文提出的方法论（核心思想、关键技术细节）

- **模型架构**：
  - 基于**冻结的 DINOv3 骨干网络**（frozen backbone），其上叠加一个紧凑的**因果 Transformer**。
  - 整个模型称为 **ValueFormer**，是一个**策略无关**（policy-agnostic）的批评器，可独立于策略运行。

- **双输出头**：一次前向传播同时输出两个每帧信号：
  - **V_mc**：平滑的蒙特卡洛价值（Monte Carlo value），用于优势估计（advantage estimation）；
  - **二值检测信号**：尖锐的在线错误检测值，用于判断当前帧是否处于错误状态。
- **设计悖论与解法**：平滑价值与尖锐检测这两个目标在方向上天然相反（平滑需要抑制突变，检测需要放大突变），作者通过精心设计目标函数使两者共存于同一模型。

- **阶段感知的成功-然后-衰减回报（Stage-Aware, Success-then-Decay Return）**：
  - 失败情节被标记为“阶段感知”的形式：在失败阶段**之前**保留完整的成功曲线，失败阶段之后则逐步衰减。
  - 这样避免了简单二值标签丢失“策略在失败前做对了什么”的信息。

- **错误区间监督（Mistake-Interval Supervision）**：
  - 检测信号不是从单一失败时刻进行监督，而是从**错误区间**（mistake intervals）进行监督。
  - 这意味着策略能够从中恢复的错误也会携带学习信号，而不仅是最终导致失败的那一次错误。

- **公式/算法流程（文字说明）**：
  1. 收集真实机器人 rollout 数据，标注成功/失败及阶段信息；
  2. 为每个失败情节构造 success-then-decay 回报曲线；
  3. 将错误区间标注为检测目标；
  4. 冻结 DINOv3 编码器，训练因果 Transformer 同时回归平滑价值 V_mc 和检测二值输出；
  5. 在部署时，批评器以 2 Hz 频率与策略并行运行，输出每帧价值与错误信号；
  6. 由批评器导出的每帧训练权重可反馈用于策略训练（重加权）。
