## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作中展现出强大潜力，但现有模型大多依赖二维视觉-语言骨干网络，缺乏对目标物体的精细三维理解，尤其是在遮挡、姿态变化、尺度变化和精确空间交互场景下。我们提出了一种以物体为中心的三维表示对齐框架，基于π0构建，使用SAM3D作为冻结的三维教师，在训练期间提供目标物体的三维先验。具体而言，我们利用物体识别模型定位与任务相关的物体，生成对应的物体掩码，并使用SAM3D提取密集的物体级三维表示，再将其与π0的中间视觉特征进行对齐。这使得策略能够内化目标物体的三维信息，同时保留原始的RGB-语言-动作推理流程，且在测试时无需深度、点云、掩码、SAM3D或额外三维模块。仿真实验显示了一致的性能提升，在LIBERO上达到99.1%，在CALVIN上平均长度为4.11。真实世界实验进一步表明，我们的方法在需要对多个子任务中的不同目标物体保持关注的长时间跨度操作场景中尤为有效。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for general robot manipulation, but most existing models rely on 2D visual-language backbones and lack fine-grained 3D understanding of target objects, especially under occlusion, pose variation, scale changes, and precise spatial interaction. We propose an object-centric 3D representation alignment framework built upon $π_0$, using SAM3D as a frozen 3D teacher to provide target-object 3D priors during training. Specifically, we localize task-relevant objects with object recognition models, generate corresponding object masks, and use SAM3D to extract dense object-level 3D representations, which are aligned with intermediate visual features of $π_0$. This enables the policy to internalize target-object 3D information while preserving the original RGB-language-to-action inference pipeline without requiring depth, point clouds, masks, SAM3D, or additional 3D modules at test time. Simulation experiments show consistent improvements, achieving 99.1\% on LIBERO and an average length of 4.11 on CALVIN. Real-world experiments further demonstrate that our method is particularly effective in long-horizon manipulation scenarios where the robot must focus on different target objects across multiple subtasks.

# SAM3D-VLA 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心瓶颈**：现有 VLA（Vision-Language-Action）模型大多基于 2D 视觉-语言骨干网络，缺乏对目标物体的精细 3D 理解，在遮挡、姿态变化、尺度变化和精确空间交互（如插拔、放置）等场景下性能受限。
- **已有方法的不足**：
  - 显式引入 3D 输入（深度图、点云、RGB-D）的方法虽提升空间感知，但需要额外传感器且改变策略输入接口。
  - 隐式空间对齐方法（如 Spatial Forcing）侧重于全局场景级空间监督，而非目标物体级别的 3D 先验。
  - 2D 视觉定位方法（裁剪、包围框等）停留在图像空间，无法提供物体真实的 3D 形状与布局信息。
- **核心研究问题**：能否在不改变 VLA 模型原始推理流程（RGB + 语言 → 动作）的前提下，将目标物体的 3D 先验注入策略网络？
- **整体思路**：以 π0 为基座，利用冻结的 SAM3D 作为 3D 教师，在训练阶段将物体级 3D 特征对齐到 π0 的中间视觉特征上，测试时无需任何 3D 输入或模块。

## 2. 方法论：核心思想与关键技术

- **总体框架**（SAM3D-VLA）：
  - 基于 π0 架构（SigLIP 视觉编码器 + Gemma 语言模型 + 连续动作专家），训练时在中间层引入 SAM3D 特征对齐损失，推理时保持原始 π0 RGB-语言到动作的流程不变。
- **SAM3D 引导的物体中心特征对齐**：
  - 将多视角 RGB 图像和物体掩码展平后输入冻结的 SAM3D，提取密集物体级 3D 特征（包含形状、表面结构、空间布局等几何先验）。
  - 通过空间重采样（将教师 token 序列重排为 2D 特征网格后双线性插值到学生视觉 token 分辨率）和维度投影（MLP 将学生特征映射到 SAM3D 特征空间），实现逐 token 对齐。
  - 使用掩码归一化均方误差（masked normalized MSE）作为对齐损失，仅对任务相关物体区域做特征方向对齐。
- **训练目标**：L = L_action + α·L_align，其中 L_action 为 π0 的条件流匹配动作损失，α 控制 3D 监督强度。
- **子任务感知数据处理**：
  - 针对长时程任务，用大语言模型（GPT-4o）将高层指令分解为多个子任务，每个子任务关联对应的目标物体。
  - 使用 Grounding DINO / YOLO 检测目标物体，SAM2 生成掩码，再输入 SAM3D 提取该子任务的 3D 特征，提供阶段特定的监督信号。
- **冻结表示探针（Frozen-representation Probing）**：
  - 训练完成后冻结 VLA 骨干，仅训练一个轻量 MLP 探针从中间特征预测 SAM3D 特征，用探针性能衡量 3D 信息在 VLA 特征中的可恢复性。

## 7. 方法优点与亮点

- **推理与训练解耦**：3D 监督仅作用于训练阶段，推理时保持原始 π0 流程，无额外部署开销。
- **物体中心监督粒度**：区别于全局场景级 3D 对齐，聚焦目标物体 token，更精准地注入与操纵直接相关的几何信息。
- **子任务感知 3D 监督**：针对长时程任务分解指令，为不同阶段提供不同的目标物体 3D 先验，有效缓解多物体场景下的注意力漂移。
- **归一化掩码对齐损失**：在归一化空间做方向性对齐，避免了 SAM3D 与 π0 特征尺度不匹配问题。
- **可解释性验证设计**：通过冻结表示探针实验从机制上证明 3D 信息确实被编码进 VLA 特征，为方法有效性提供了更深入证据。
- **与架构无关的通用框架**：对齐框架不限定于 π0，可迁移到其他 VLA 骨干。
- **开源模型组成的自动化管线**：Grounding DINO + SAM2 + SAM3D 全部为开箱即用的模型，数据标注流程自动化。
