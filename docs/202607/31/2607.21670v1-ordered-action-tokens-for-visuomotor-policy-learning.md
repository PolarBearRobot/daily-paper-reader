## 摘要
动作标记化将连续的机器人动作块映射为离散标记，并已成为现代视觉运动策略的重要接口。现有方法要么依赖分析性离散化方法，产生过长的标记序列，要么缺乏结构的学得潜在标记器，限制其与下游策略的兼容性。在本工作中，我们确定了动作标记化的三个期望特性——高压缩性、完全可解码性和有序标记空间——并引入有序动作标记化（OAT），这是一种满足所有三个特性的学得动作标记器。OAT使用带有寄存器、有限标量量化和排序诱导训练机制的Transformer，将动作块离散化为有序标记序列。通过训练每个标记前缀解码为有效的动作块，OAT将粗粒度控制信息置于早期标记中，并使用后续标记细化残差细节，从而在推理成本与动作保真度之间实现任意时的权衡。我们在动作标记的两种主流用法中验证了OAT：用于生成控制标记的自回归策略，以及使用标记损失来塑造流式动作专家消费的视觉-语言模型上下文的标记协同训练策略。跨三个策略主干和涵盖五个模拟基准及真实世界设置的60多个任务，OAT一致地提供强大的策略性能，同时在推理时提供显著更大的灵活性。

## Abstract
Action tokenization maps continuous robot action chunks to discrete tokens and has become an important interface for modern visuomotor policies. Existing approaches either rely on analytical discretization methods that produce prohibitively long token sequences or learned latent tokenizers that lack structure, limiting their compatibility with downstream policies. In this work, we identify three desiderata for action tokenization - high compression, total decodability, and an ordered token space - and introduce Ordered Action Tokenization (OAT), a learned action tokenizer that satisfies all three. OAT discretizes action chunks into an ordered sequence of tokens using a transformer with registers, finite scalar quantization, and ordering-inducing training mechanisms. By training each token prefix to decode into a valid action chunk, OAT places coarse control information in early tokens and uses later tokens to refine residual detail, yielding an anytime tradeoff between inference cost and action fidelity. We validate OAT in two prevailing uses of action tokens: autoregressive policies that generate tokens for control, and token co-training policies that use token losses to shape the vision-language model context consumed by a flow-based action expert. Across three policy backbones and more than 60 tasks spanning five simulation benchmarks and real-world settings, OAT consistently delivers strong policy performance while offering significantly greater flexibility at inference time.

## 论文总结：Ordered Action Tokens for Visuomotor Policy Learning（有序动作标记用于视觉运动策略学习）

### 1. 核心问题与整体含义（研究动机与背景）

- 在视觉运动策略学习中，**动作标记化（Action Tokenization）** 是将连续机器人动作块映射为离散标记序列的关键接口技术，直接影响策略的学习难度、推理成本和控制效果。
- 现有动作标记化方法存在明显不足，难以兼顾以下三个核心需求：
  - **高压缩性（High Compression）**：标记序列应尽量短，否则策略需预测过多目标，训练困难且推理延迟高。
  - **完全可解码性（Total Decodability）**：策略生成任意标记序列都应能解码为可执行的动作，而非仅对训练中的编码有效。
  - **有序结构（Ordered Structure）**：早期标记应包含控制中的粗粒度关键信息，后续标记用于细化残差细节，从而为自回归预测或监督学习提供有利的归纳偏置。
- 现有方法各自的缺陷：
  - **逐维分箱（Bin）**：可解码性高但序列过长，且缺乏有序结构；
  - **频域方法（FAST）**：有频率顺序但 BPE 压缩导致解码并非完全定义，任意采样可能无法还原固定形状系数数组；
  - **学得潜在标记器（QueST、ACodec）**：压缩率高且可解码，但仅优化重建损失无法保证将控制相关信息放在早期标记中，缺乏有序性，且对可扩展的块式生成不友好。
- 本文提出 **有序动作标记化（OAT）**，力图同时满足高压缩、完全可解码与有序标记空间三个特性，为策略预测和监督提供更好的接口。

### 2. 方法论：OAT 的核心思想、关键技术与算法流程

**核心思想**：利用带寄存器的 Transformer 编码器 + 有限标量量化（FSQ）+ 嵌套 dropout（Nested Dropout）训练机制，学习一种有序的离散动作标记序列。该序列的每个前缀都能解码为有效且可执行的完整动作块，从粗到细渐进式地表达动作。

**关键技术细节**：

- **寄存器瓶颈（Register Bottleneck）**：
  - 编码器使用可学习寄存器向量，每个寄存器交叉关注所有动作位置，将连续动作块压缩为固定长度的寄存器状态序列。
  - 再用 FSQ 将每个寄存器状态离散化为动作标记，构成策略的预测目标（token）。

- **嵌套前缀重建（Nested Prefix Reconstruction）**：
  - 设定训练预算集合 K = {1, 2, 4, ..., Hl}（如 {1,2,4,8,16}），训练时随机采样预算 K。
  - 仅保留前 K 个标记，后缀替换为学得的 **MASK** 标记，再送入解码器重建完整动作块。
  - 训练目标为重建误差（均方误差）：使解码器能将任意保留前缀映射为可执行动作，而非仅优化完整序列重建。

- **寄存器流约束（Register Flow Constraints）**：
  - 通过控制寄存器自注意力掩码（token-wise 因果掩码或 power-of-two 块因果掩码），决定同一预算区间内寄存器间的依赖结构。
  - **OAT_sing**（token-wise）：普通因果注意力，每个 token 位置形成依赖链，适合 token-wise 自回归生成。
  - **OAT_pow2**（power-of-two）：块因果掩码，允许同组寄存器独立编码，使同组 token 可被并行预测，与分组自回归生成模式匹配。

- **渐进信息分配解释**：嵌套 dropout 使每个 token 的生存概率 P(K≥i) 非递增，因此前段 token 获得更大的重建压力，促使粗粒度信息靠前、细粒度残差靠后，形成一种学得的 rate–distortion 权衡曲线。

**BAR（Block-wise Autoregressive）生成框架**：

- 将生成过程定义为从目标预算 K 到端点列表 b = (b0, ..., bS) 的分块自回归调度，统一了 token-wise 自回归、一次性并行解码、固定块预测等模式。
- OAT_pow2 使用端点 (1, 2, 4, 8, 16)，将完整生成的**策略调用次数从 O(Hl) 降至 O(log Hl)**，显著降低推理时延。

**Token Co-Training（TC）模式**：

- OAT 标记作为 VLM 的监督目标（交叉熵损失），同时流匹配专家消费冻结的 VLM 上下文（stop-gradient）产出连续动作。
- 由于第一个 OAT 目标仅由观测上下文直接预测，因此在对 VLM 预填充表示施加了“计划级”的整块摘要监督，这种监督方式比坐标分箱更有全局意义。

### 6. 主要结论与发现

- **OAT 满足三大设计需求**：高压缩、完全可解码、有序标记结构。前缀解码始终产生可执行动作块。
- **OAT 在所有规模的策略上均表现优异**：
  - 轻量策略中，OAT_sing 8 在所有模拟 benchmark 和真实任务上取得最高成功率，平均排名第一；
  - VLM AR 中，PaliGemma2 上 OAT_sing 16 达 63.7，OAT_pow2 16 用 5 次调用即达 63.8，几乎无损且推理开销大幅下降；
  - VLM TC 中，Qwen3VL 上 OAT 平均成功率 62.5，为所有 tokenizer 最高。
- **有序性是 OAT 性能的关键来源**：去除排序训练（OAT_sing×）后策略性能显著下降，说明仅有压缩和重建还不够。
- **BAR 与 tokenizer 的匹配很重要**：对 OAT_sing 事后施加分组生成会导致成功率下降（79.7 → 66.3），而匹配模型结构的 OAT_pow2 达到 80.8。
- **动作时间范围与标记容量应联合设计**：更大 Ha 需要更大 Hl 补齐；固定 8 步执行下 Ha=32、Hl=8 是较好折中。
- **中等码本容量最优**：FSQ 词表约 1000–2000 时策略表现最好，过小限制表征、过大增加预测难度。
