## 摘要
世界动作模型（WAM）通过联合建模动作和未来观测来改进机器人策略学习。然而，仅以任务提示和观测上下文为条件进行未来预测，可能会捕捉到通用的任务进展，而非所执行动作引发的特定后果。我们引入了SelfWAM，这是一种基于模态特化混合变换器（MoT）架构的统一自接地WAM，它联合预测动作、动作条件下的未来RGB帧和机器人自掩码，从而将未来预测接地于机器人的可见身体及其动作引发的运动。在联合训练过程中，SelfWAM允许未来视觉查询关注演示动作的干净副本，将视频分支转变为动作特定的后果模型，同时保持仅基于动作的快速推理路径不变。为了将视频学习聚焦于与动作相关的视觉变化，我们使用针对未来机器人自掩码预测的提示特定目标，这去除了外观细节，并提供了一个其时间演化与条件动作紧密耦合的目标。共同地，干净动作条件和未来自掩码监督使未来预测更直接地反映所执行动作如何改变机器人的可见运动及周围场景。在RoboTwin 2.0和真实世界操作任务上的实验表明，SelfWAM产生了对动作更敏感的未来预测，保持了快速策略推理，同时提升了策略性能。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future observations. However, conditioning future prediction only on the task prompt and observation context risks capturing generic task progression rather than the action-specific consequences of the executed action. We introduce SelfWAM, a unified self-grounded WAM built on a modality-specialized Mixture-of-Transformers (MoT) architecture that jointly predicts actions, action-conditioned future RGB frames, and robot self-masks, thereby grounding future prediction in the robot's visible body and its action-induced motion. During joint training, SelfWAM allows future visual queries to attend to a clean copy of the demonstrated action, turning the video branch into an action-specific consequence model while leaving the fast action-only inference path unchanged. To focus video learning on action-relevant visual changes, we use prompt-specific objectives for future robot self-mask prediction, which removes appearance details and provides a target whose temporal evolution is tightly coupled with the conditioning action. Together, clean-action conditioning and future self-mask supervision make future predictions more directly reflect how the executed action changes the robot's visible motion and the surrounding scene. Experiments on RoboTwin 2.0 and real-world manipulation tasks show that SelfWAM produces more action-sensitive futures and preserves fast policy inference, while improving policy performance.

## 1. 核心问题与研究动机

- **背景**：世界动作模型（WAM）将动作预测与未来视觉建模联合训练，借力预训练视频生成先验来提升机器人策略学习。最近的工作（如 FastWAM）已经表明，大部分收益可以在部署时不生成未来视频的情况下获得——未来视频预测仅作为联合训练目标。
- **核心问题**：现有的 WAM 未来预测仅以观测、语言指令和本体感觉为条件，**没有显式利用产生该未来帧的演示动作**。这导致视觉预测倾向于捕捉通用的任务进展（generic task progression），而非区分不同动作引发的具体视觉后果，削弱了世界模型对动作选择的指导价值。
- **研究动机**：论文主张动作面策略世界模型应回答"在某个特定动作下未来会如何变化、变化发生在哪里、机器人自身如何介入"，因此需要自接地（self-grounded）未来预测——显式建模机器人可见身体及其动作诱导的运动，并让未来预测在训练时直接依赖演示动作。

## 2. 方法论

### 2.1 核心思想

- 引入**干净动作条件路径（clean-action conditioning）**：在训练时，将演示动作的干净副本（不添加噪声）仅暴露给未来视觉查询，使视频分支成为"动作特定的后果模型"。
- 引入**未来机器人自掩码预测（future self-mask prediction）**：用自掩码目标去除外观、纹理、光照等与动作弱相关的视觉信息，迫使模型聚焦于动作直接引发的、机器人自身的可见运动。
- 两者共同将未来预测从"被动的旁观者"转化为"主动的行动者"，同时保持部署时动作-only 快速推理路径不变。

### 2.2 架构与信息流

- 基于 FastWAM 的两流**模态特化混合变换器（MoT）**：预训练视频主干 + 轻量动作专家，通过混合注意力耦合。
- 训练时的注意力方向模式：
  - 噪声动作查询 → {当前上下文, 噪声动作}
  - 未来视觉查询 → {当前上下文, 未来视觉, **干净动作**}
  - 干净动作查询 → {当前上下文, 干净动作}
- 关键设计：**不对称信息流**。干净动作和未来视觉 token 对策略分支不可见，防止目标泄漏；部署时省略干净动作和未来视觉流，计算图与纯动作推理完全一致。
- 视频主干同时支持两个输出域：未来 RGB 帧和未来自掩码帧，通过不同输出提示区分；使用相同的时空 token 布局、位置编码和噪声调度。
- 总体训练目标：`L = λ_act·L_act + λ_video·L_rgb/mask`，自掩码实例仅贡献视觉损失，不包含动作去噪监督。

## 3. 实验设计

### 3.1 Benchmark 与数据集

- **RoboTwin 2.0**：大规模双臂操作仿真基准，50+ 任务。训练集 27,500 条演示（2,500 条干净环境 + 25,000 条强场景随机化），每任务 100 次 rollout，分别报告干净/随机化设置下的成功率。
- **真实机器人**：AgileX ALOHA 双机械臂平台，4 个桌面操作任务（杯→支架、笔→杯、鼠标→鼠标垫、纸球→垃圾桶），17,307 个 episode（约 955 万 transition），基于固定随机种子的 episode 级划分。自掩码利用 RobotSeg（SAM 2）离线生成。

### 3.2 对比方法

- VLA 基线：π0、π0.5
- WAM 基线：Motus、GigaWorld-Policy、FastWAM
- 所有模型在相同数据集和协议下训练评估。

### 3.3 评估指标

- 策略性能：任务成功率
- 未来预测质量：LPIPS、PSNR、FVD-I3D
- 动作敏感性：WorldArena 的 Action Following + 三项一致性指标、方向性动作扰动（上下左右）、连续动作插值实验

主要实验组包括：

**充分性判断**：实验设计较完整，覆盖了策略性能、未来预测质量、动作敏感性、消融和效率等多个维度；消融实验验证了各组件的增量贡献；未来预测方面同时使用参考性指标（LPIPS/PSNR/FVD）和诊断性指标（Action Following、扰动/插值测试），避免了单一指标的偏差风险。不足之处在于真实机器人任务仅 4 个、每任务仅 10 次试验，统计显著性测试未报告。

## 6. 主要结论与发现

- **动作条件化显著提升未来预测质量**：相比观测条件化（FastWAM），动作条件的未来预测在 LPIPS（0.0636→0.0429）、PSNR（29.24→32.79）和 FVD-I3D（45.92→34.55）上有全面改进。
- **动作敏感性显著增强**：方向扰动和连续插值实验显示，SelfWAM 的预测随动作指令按预期方向/程度连续变化，而动作无条件的基线几乎不变。
- **策略性能提升**：RoboTwin 2.0 上 SelfWAM 成功率最高（clean 92.16%、random 93.08%、平均 92.62%），真实机器人 4 任务平均 95%（FastWAM 85%、π0.5 90%）。
- **自掩码监督提供互补收益**：消融显示干净动作条件本身基本保持性能，自掩码监督带来干净和随机化场景下的进一步提升。
- **推理成本几乎不变**：动作-only 延迟仅增加 0.97%，峰值显存零增长。

## 7. 优点

- **概念清晰且新颖**：将"自接地"概念落地为干净动作条件和自掩码监督两个具体、可操作的机制，直击 WAM 未来预测动作无关的问题。
- **不对称信息流设计精巧**：通过注意力规则设计，干净动作只供给视觉分支，既实现动作条件的视觉建模，又防止目标泄漏，使部署路径与训练策略路径完全一致。
- **自掩码目标选择得当**：去除了外观和背景干扰，让学习信号聚焦于动作直接相关的机器人可见运动，与动作结构紧密耦合。
- **保持快速推理**：继承了 FastWAM 的动作-only 部署设计，附带极低的额外成本，实用性强。
- **实验验证充分多维**：从策略性能、未来预测质量、动作敏感性（扰动+插值）、消融、效率等多个角度验证方法，且提供了完整的任务级结果和层级一致性诊断，透明度和可复现性较好。

## 8. 不足与局限

- **未建模接触、力和遮挡**：论文在 Limitations 中承认，未显式建模接触力、交互力或被遮挡的交互，对接触密集的操作任务覆盖不足。
- **自掩码质量依赖分割模型**：真实机器人训练依赖 RobotSeg 离线生成的 mask，分割误差可能引入监督噪声；论文未分析 mask 质量对最终性能的影响。
- **真实实验规模有限**：仅 4 个桌面任务、每任务 10 次试验、仅与 FastWAM 和 π0.5 对比，未包含 Motus 等更强的 WAM 基线，统计显著性未报告。
- **算力门槛极高**：64×A800×30h 的训练成本对一般研究组不友好，限制了方法的可复现性和可及性。
- **评价指标的局限**：未来预测质量评估基于与真实未来帧的相似度，参考性指标本身需要额外的动作敏感性实验来补充说明——论文已经这么做了，但 FVD/LPIPS 在动作条件化下的解释仍需仔细对待。
- **自掩码采样比例不均衡**：RGB 与自掩码实例采样比为 9:1，自掩码监督权重较低，其贡献的定量分析（如不同比例的影响）未提供。
- **跨体现泛化未验证**：自掩码设计理论上有利于减小不同机械臂外观差异，但论文未进行跨机械臂迁移实验。
- **任务类型覆盖有限**：仿真与真实实验均集中在桌面近距离操作，未涉及移动操作、长时程任务或非刚体操作，其通用性尚需验证。
