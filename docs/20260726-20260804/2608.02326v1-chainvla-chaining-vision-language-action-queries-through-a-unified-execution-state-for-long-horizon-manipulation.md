## 摘要
人类通过保留先前动作已建立的知识，同时不断调整进行中的运动，来执行长时程操作。相比之下，动作分块的视觉-语言-动作（VLA）策略在每次查询时从当前输入重复规划。现有方法要么通过记忆保留长期任务证据，要么通过动作重用和集成保留短期运动，导致跨查询交接不完整。我们提出了ChainVLA，一个1.2B参数的VLA策略，通过联合且可修订的执行状态链接连续查询。进度上下文将循环工作状态与稀疏事件记忆相结合，以携带源自观察的任务进度，而运动尾部则将先前预测的未执行延续部分馈入状态构建和动作生成。这两个组件共同条件化一个解码器，在最新观察下重新生成每个动作视野，使得携带的状态能够指导下一次预测而不固定它。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%，而移除运动尾部或进度上下文分别将RMBench成功率降至11.2%和3.0%。这些不对称的消融与运动连续性有助于保留从中推断任务进度的观察流这一观点一致。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

# ChainVLA 论文总结

## 1. 核心问题与研究动机

- **背景**：长时程操作任务中，人类依赖两种能力协同工作——**任务进度记忆**（记住已完成的任务）与**运动连续性**（保持和调整进行中的动作）。
- **现存问题**：动作分块式 VLA（Vision-Language-Action）策略通过重复的 receding-horizon 查询来执行任务，每次查询独立地从当前观测和指令重新预测动作块，导致两个层面的跨查询信息丢失：
  - **任务层面**：早期任务证据可能无法从当前视角中恢复（如 RMBench 的 Put Back Block 任务，相同的观测和指令可能对应不同的历史轨迹，需要不同的后续决策）。
  - **运动层面**：重新规划丢弃了前一次预测中未执行的部分，导致新动作块与它所替代的运动不连续。
- **现有方法不足**：记忆增强方法（MemoryVLA 等）保留观测衍生的历史证据但忽略预测侧的运动延续；时间集成/实时执行方法（Temporal Ensemble 等）保留短期运动但无法回溯早期任务证据。两类方法相互独立，无法兼顾。
- **核心研究问题**：如何在一个 VLA 策略中同时跨查询链接**任务进度**与**运动延续**，同时保持每个新预测对最新观测的响应性？

## 2. 方法论

### 2.1 核心思想
ChainVLA 引入**联合且可修订的执行状态**，将连续查询链接起来。该状态由两部分组成：

- **Progress Context（进度上下文，gk）**：携带观测衍生的任务进度，由循环的 Working State（工作状态）与稀疏事件记忆（Sparse Event Memory）融合而成。
- **Motion Tail（运动尾部，uk）**：携带前一次预测中未执行的运动延续（suffix），直接跨查询传递。

### 2.2 查询转移机制
查询转移形式化表达为：

```
(Ak, Wk, Ck+1) = Fθ(xk, Dk, Wk−1, Ck, uk)
uk+1 = Tail(Ak)
```

其中 xk 为当前查询输入（观测+本体状态+指令），Dk 为已执行动作历史，Wk 为循环工作状态，Ck 为稀疏事件记忆，uk 为传入运动尾部。执行严格前缀（hexec）后，未执行的后缀成为下一查询的运动尾部。

### 2.3 关键技术细节

- **Recurrent Working State**：使用 8 个学习的工作查询（working queries）关注当前多模态 token，并通过循环连接前一个实时 token 来更新状态。更新过程包括条件池化向量 ηk 的计算、CrossAttn 更新实时 token Lk、池化执行/尾部/状态 token 生成检索摘要。
- **Sparse Event Memory**：存储稀疏事件记录（64 视觉 token + 8 阶段信息 + 8 时态特征 + 检索键 + 写入时刻索引），采用锚点保留和最高分数非锚点检索策略，使用**年龄感知余弦相似度**进行检索。带阶段标注的数据用阶段转移触发写入；无标注数据用周期性写入规则。
- **Motion Tail 双路径**：
  - **路径一**：将尾部的动作归一化后编码为 tail token，注入 Working State 构建。
  - **路径二**：将尾部与全视野动作表示对齐，作为条件流解码器的初始状态（高斯噪声围绕 μk+1），实现“可修订先验”而非固定计划。
- **解码器**：使用 DiT（Diffusion Transformer）条件流解码器，在最新观测、Progress Context 和 Motion Tail 条件下重新生成完整动作视野（每个位置均可修改）。
- **训练策略**：按 episode 顺序展开，下一查询以 0.5 概率使用前驱的分离预测尾部；包含重叠一致性正则化器用于运动尾部交接。

## 3. 实验设计

### 3.1 基准与任务

- **RMBench**（主要诊断场景）：记忆依赖的操作基准，包含 5 个任务（Observation, Rearrange Blocks, Put Back Block, Swap Blocks, Swap Things），每个任务训练独立适配模型，100 个 rollout episode。
- **LIBERO**（广度验证）：包含 Spatial、Object、Goal、Long 四个套件，每个套件微调一个模型，每个任务 50 个 episode。

### 3.2 对比方法

- 行动分块方法：DP、ACT、π0.5、X-VLA、π0-FAST、GR00T-N1、π0
- 记忆增强方法：MemER、MemoryVLA、Mem-0、MemoAct、PAM、Goal2Skill
- 其他：OpenVLA、SpatialVLA、CronusVLA（部分仅参考报告值）

### 3.3 消融与对照实验

- **Progress Context 侧**：去除阶段标注（w/o Stage Ann.）、去除实时 token（w/o Live Tokens）、去除事件读入（w/o Event Readout）、去除整个进度上下文（w/o Progress Ctx.）
- **Motion Tail 侧**：去除尾部 token（w/o Tail Tokens）、去除轨迹初始化（w/o Traj. Init.）、去除整个运动尾部（w/o Motion Tail）
- **无状态对照**：两者都去除（w/o Both）、替换为 FIFO 观测历史 + 时间集成（FIFO Hist. + TE）
- **配对场景边界 rollout**：Put Back Block（20 对）、Rearrange Blocks（30 对）、Swap Blocks（30 对），共 80 对
- **后解码平滑控制**：Linear Continuation、Temporal Ensemble

## 6. 主要结论

1. **统一执行状态链式传递有效**：ChainVLA 在 RMBench 上达到 62.8% 平均成功率（最佳对比 Mem-0 为 52.8%，但参数规模为 8B+2B），在 LIBERO 四套件平均 98.8%（Long 达到 98.2%）。
2. **任务进度与运动尾部互为依赖**：去除 Motion Tail 后成功率降至 11.2%，去除 Progress Context 后降至 3.0%，证明二者的贡献是**串联而非并联**关系。
3. **运动连续性支持记忆推断**：运动尾部通过保持动作边界平滑性，保护了观测流的分布一致性，从而保障了任务进度估计的可靠性（不对称消融证据 + 配对 rollout 的边界诊断支持此假设）。
4. **后解码平滑无法替代模型侧条件化**：Linear Continuation 等方案虽能降低边界误差，但无法恢复成功率（0% 对 96%），说明必须在状态构建和生成阶段就引入延续先验。
5. **阶段标注并非必需**：无标注场景的周期性写入规则（w/o Stage Ann.）仍能达到 53.4% 的平均成功率，仅比完整模型低 9.4 个百分点。

## 7. 方法优点

- **概念清晰**：将跨查询交接问题拆分为任务进度（回顾性）与运动延续（前瞻性）两类互补信号，且以“可修订先验”而非固定计划的形式输入解码器，保持了对最新观测的响应性。
- **统一的状态传递框架**：训练与 rollout 共享相同的查询转移方程，减少了 train-inference 分布偏移。
- **实验设计严密**：匹配消融 + 配对场景边界诊断 + 后解码平滑对照三位一体，支撑“运动连续性帮助保护观测流”这一机制假设；用替代方案控制混淆变量，因果论证链条清晰。
- **参数量效率高**：1.2B 参数达到超过 8B+2B 记忆模型的效果，在资源效率和性能之间取得良好平衡。

## 8. 不足与局限

- **评估范围受限**：所有结果来自固定频率仿真（RMBench/LIBERO），未在真实硬件部署，也未测试异步或实时控制场景；边界诊断度量的是命令流而非物理轨迹平滑度。
- **统计信度有限**：单随机种子，无显著性检验，成功率与边界指标为点估计；论文对此有明确声明，但统计学上的稳健性仍存疑。
- **外部基线不可比**：对比行来自原文报告，未在同一协议下重跑，可能在骨干、演示数量、优化预算和成功准则上存在差异。
- **机制因果链未被严格验证**：运动连续性对任务进度支持的机制性解释是建立在关联性证据之上的，作者明确承认未建立完整的因果链。
