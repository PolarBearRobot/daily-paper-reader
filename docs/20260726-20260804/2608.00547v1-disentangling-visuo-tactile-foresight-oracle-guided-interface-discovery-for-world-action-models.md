## 摘要
接触丰富的操作仍然具有挑战性，因为成功的控制依赖于通常仅从视觉中难以观察到的物理交互线索。最近触觉世界动作模型联合建模未来的视觉观察和触觉信号以指导动作生成，但如何构建这些未来以供动作专家有效使用仍未得到充分探索。直接通过学习世界动作模型研究这个问题是困难的，因为端到端行为纠缠了物理上无效的视觉未来、不可靠的预测、不准确或跨模态不一致的触觉预测，以及不可读的未来到动作接口。为了使该接口可独立研究，我们引入了Oracle视觉-触觉预见（OVTF），这是一个受控框架，从模拟中验证的成功轨迹提供配对的RGB和触觉未来。通过固定未来提供者，OVTF隔离了接口并提出了一个更清晰的问题：如果未来是成功且物理可执行的，什么样的表示能使动作专家吸收其益处？在OVTF内，我们提出了不对称相位局部未来记忆（AFM），其中视觉记忆读取未来视觉，每个触觉记忆共同关注自己的触觉流和相位对齐的未来视觉，并阻止跨触觉访问。我们将AFM与模态隔离未来记忆（IFM）进行比较，后者移除了视觉到触觉的访问并独立处理每个未来模态。在UniVTAC模拟基准的七个任务中，AFM平均成功率达到32.0%，而IFM为23.7%，UniVTAC-ACT为14.9%。这种受控比较表明，选择性的相位对齐视觉-触觉路由比完全模态隔离提供了更具可操作性的未来到动作桥梁。

## Abstract
Contact-rich manipulation remains challenging because successful control depends on physical interaction cues that are often weakly observable from vision alone. Recent tactile world action models jointly model future visual observations and tactile signals to guide action generation, but how such futures should be structured for effective use by the action expert remains underexplored. Directly studying this question with learned world action models is difficult because end-to-end behavior entangles physically invalid visual futures, unreliable predictions, inaccurate or cross-modally inconsistent tactile forecasts, and an unreadable future-to-action interface. To make this interface independently studyable, we introduce Oracle Visuo-Tactile Foresight (OVTF), a controlled framework that supplies paired RGB and tactile futures from successful trajectories verified in simulation. By fixing the future provider, OVTF isolates the interface and asks a cleaner question: if the future is successful and physically executable, what representation allows the action expert to absorb its benefit? Within OVTF, we propose Asymmetric Phase-Local Future Memory (AFM), in which visual memory reads future vision, each tactile memory jointly attends to its own tactile stream and phase-aligned future vision, and cross-tactile access is blocked. We compare AFM with Modality-Isolated Future Memory (IFM), which removes visual-to-tactile access and processes each future modality independently. Across seven tasks on the UniVTAC simulation benchmark, AFM achieves 32.0% average success, compared with 23.7% for IFM and 14.9% for UniVTAC-ACT. This controlled comparison shows that selective phase-aligned visual-tactile routing provides a more actionable future-to-action bridge than complete modality isolation.

- 直接使用端到端学习的 WAM 来研究该问题是困难的，因为最终任务分数中纠缠了四种因素：
  1. 物理上无效的视觉未来；
  2. 动作分支对未来分支的"不信任"（因预测不稳定而学会忽略未来信息）；
  3. 不正确或跨模态不一致的触觉预测；
  4. 未来到动作接口本身设计不佳。

**整体含义**
- 论文主张：**未来预测的准确性与未来到动作接口的质量是两个可分离的问题**。只有将未来提供者（future provider）固定为理想来源，才能独立研究接口设计。
- 该研究试图回答一个更干净的问题：**如果未来是成功的、物理可执行的，什么样的表示能让动作专家真正吸收其益处？**

## 2. 论文提出的方法论

### 2.1 核心思想：Oracle Visuo-Tactile Foresight (OVTF)
- OVTF 是一个**变量解缠框架**：从成功演示轨迹中提供配对的、按时间顺序排列的、与当前初始化匹配的、并在仿真中验证成功的 RGB 和触觉未来序列。
- 该框架**移除/固定了学习式未来预测器**，使未来到动作接口成为唯一可独立研究的变量。
- 关键设计：oracle 只提供未来视觉图像和左/右触觉 RGB 图像，**不提供未来动作、未来 qpos、物体位姿、仿真器状态等特权元数据**，是一个纯诊断性来源。

### 2.2 技术细节

**未来来源与采样**
- 从与当前初始化配对的成功 HDF 演示轨迹采样最多 N = 100 帧。
- 定义了归一化剩余相位（normalized remaining-horizon phase）：
  - φᵢ = (τᵢ − τ_ref) / max(1, T − 1 − τ_ref)，φᵢ ∈ [0, 1]
- 在 rollout 时，策略调用索引 p 设定 τ_ref = min(⌊p/2⌋, T − 1)，再按同一相位定义采样最多 100 帧。

**未来编码**
- 未来视觉帧和触觉帧各由**可训练的 ResNet-18** 编码，初始化为 UniVTAC-ACT* 对应编码器权重的深拷贝。
- 产生三个序列：H, L, R ∈ R^(N×512)（视觉、左触觉、右触觉）。
- 每个序列经过**门控局部时间残差**：
  - X′ₘ = Xₘ + tanh(gₘ) · Conv_DW(LN(Xₘ))
  - Conv_DW 是 kernel size 5、512 组的 depthwise Conv1d；三个门 gₘ 初始化为零，保证初始化时不引入新增残差。

**Asymmetric Phase-Local Future Memory (AFM)**
- 包含 12 个可学习的 512 维 slot：4 个视觉 + 4 个左触觉 + 4 个右触觉。
- 固定相位锚点：C = {0.125, 0.375, 0.625, 0.875}。
- 每个 slot 通过联合多头注意力读取允许的源序列，注意力得分包含内容项和高斯相位先验：
  - score = (q·k)/√64 − (φᵢ − c_k)² / (2 × 0.18²)
- **AFM 的路由模式**：
  - H ← H（视觉读视觉）
  - L ← (L, H)（左触觉读自身触觉 + 视觉）
  - R ← (R, H)（右触觉读自身触觉 + 视觉）
  - **L ↔ R 跨触觉访问被禁止**
- 对比的 **IFM（Modality-Isolated Future Memory）** 路由模式：H ← H, L ← L, R ← R，完全隔离各模态。

**ACT 集成**
- 当前视觉/触觉观测由冻结的 UniVTAC-ACT* 编码器处理，qpos 经冻结状态投影，构成当前空间记忆。
- 每个未来 slot 乘以零初始化的 tanh 门后，与当前记忆共同组成 ACT 编码器内存。
- 训练目标为 masked action L1 损失，CVAE/动作编码器被禁用（latent z 始终为零）。

## 3. 实验设计

**Benchmark**
- 使用 **UniVTAC 仿真基准**（UniVTAC simulation benchmark），这是一个统一的视觉-触觉操作数据生成、学习和基准测试平台。
- 实验在 **7 个操作任务** 上进行：
  1. Put Shelf（放置到架子）
  2. Pull Out Key（拔出钥匙）
  3. Lift Bottle（提起瓶子）
  4. Insert HDMI（插入 HDMI）
  5. Insert Hole（插入孔）
  6. Insert Tube（插入管子）
  7. Lift Can（提起罐子）

**数据划分**
- Put Shelf：episodes 0–39 训练，40–49 开发，50–99 rollout 评估。
- 其余任务：episodes 0–49 训练，50–99 rollout 评估。
- 每任务 50 次 rollout，总共 350 次评估。

**对比方法 / 条件**
1. **UniVTAC-ACT***：基准策略（基于 ACT 的 benchmark 实例化，带星号表明其与原始 ACT 的区别）。
2. **AFM Zero-Train**：不读取未来 HDF 数据，注入字面 12×512 零向量，训练和评估全程无未来信息。
3. **IFM**：相同的 oracle 未来提供者，但路由为完全模态隔离。
4. **AFM Forced-Zero**：使用 Oracle 训练的 checkpoint，但在评估时将未来内存槽全部置零。
5. **AFM Oracle**：训练和评估均使用 oracle 未来 + 不对称路由。

**公平性控制**
- 所有 AFM-family 条件使用相同的 50 行 episode/reset 映射、外层评估器、预处理、归一化、时间聚合、rollout 范围、早停、相机协议和成功谓词。

## 6. 论文的主要结论与发现

1. **AFM Oracle 显著优于基线**：平均成功率 32.0% vs UniVTAC-ACT* 的 14.9%，提升超过两倍。
2. **不对称视觉→触觉路由优于模态隔离**：AFM（32.0%）比 IFM（23.7%）高 8.3 个百分点，说明相位对齐的视觉上下文使触觉未来记忆更具可执行性。
3. **接口级融合不可被下游注意力替代**：尽管所有模态 token 后续仍可在 ACT 编码器内部交互，接口处的显式不对称融合仍然贡献了可观的性能提升——模型在接口处组织信息的方式是下游自注意力无法自行恢复的。
4. **Oracle 训练的策略确实利用了测试时未来**：Forced-Zero（19.4%）相对 Oracle（32.0%）下降明显，证明性能提升并非来自新增模块本身。
5. **无未来输入时 AFM 路径仍有效**：Zero-Train 达 20.0%，Forced-Zero 达 19.4%，均高于基线 14.9%。

**任务级发现**
- Put Shelf 和 Pull Out Key 从未来内容中受益最明显。
- Insert Tube 中 Oracle 和 Forced-Zero 同为 42%——表明该任务的增益主要是策略架构本身带来的，而非未来信息的测试时利用。
- Insert Hole 是唯一 IFM 超过 AFM 的任务，但所有条件均接近成功率下限。

## 7. 优点

1. **问题视角新颖且重要**：论文首次明确提出"未来到动作接口"是 WAM 中可独立研究的瓶颈，并通过 OVTF 进行变量解缠，方法论上具有示范意义。

## 8. 不足与局限

1. **Oracle 的部署可行性**：OVTF 使用成功轨迹作为未来提供者，这是一个"特权诊断源"而非学习式预测器。论文未讨论当未来预测器不完美时，AFM 是否仍优于 IFM——而真实场景中预测误差不可避免。
2. **仿真域局限**：所有实验在 UniVTAC 仿真中完成，未在真实机器人平台验证；触觉传感器在仿真与真实之间的 sim-to-real gap 未涉及。
3. **成功率天花板较低（整体 32%）**：任务难度高但样本量相对有限（7 任务 × 50 次 rollout），任务间差异大、统计显著性未报告（例如 Insert Hole 中 IFM > AFM 是否具有统计意义未说明）。
4. **未报告训练时间**：虽给出 GPU 数量和步数，但未给出单模型训练的实际时长（小时数）；也未报告整体实验的总算力消耗。
5. **未来信息采样策略的适用性**：oracle 采样依赖成功轨迹的"剩余相位"，该方法如何适配非成功轨迹或在线预测的未来内容？（不过 fair comparison）论文明确避免推断物理采样频率，但也意味着该相位定义与真实时间的关系未定。
6. **对 ACT 架构的依赖**：方法集成在 ACT 策略框架内，未来记忆的通用性（是否适用于 Diffusion Policy、RDT 等其他动作架构）未验证。
7. **少量设计选择未充分消融**：如高斯相位带宽 0.18、锚点数量 4、未来帧数上限 100、跨触觉阻断的必要性等，虽为零样本/训练好的消融提供部分证据，但未做参数敏感性分析。
