## 摘要
视觉-语言-动作（VLA）模型在机器人操作方面表现出色，但当标准指令被简单改写时，会出现灾难性的性能下降。尽管这种脆弱性通常通过昂贵的数据扩展来解决，但我们的探测揭示其根源在于架构而非缺乏语义理解。具体来说，我们证明当前的VLA模型在内部成功保留了正确的任务身份。失败实际上源于动态视觉观察和文本的联合编码，这引入了系统性特征偏移。由于下游动作策略对这些变化高度敏感，它无法将保留的语义转化为正确的控制指令。为了解决这一结构性瓶颈，我们提出了语义接地重绑定（GSR），这是一种优雅的干预措施，通过显式地将独立提取的任务语义与原生视觉特征融合，从头训练一个完全重新初始化的动作专家，从而绕开不稳定的联合路由。这种针对性的干预仅使用标准示范即可显著恢复改述不变性。在LIBERO-Para基准上，GSR将成功率提升了高达44.6%。它使轻量级模型能够与大规模扩展的基线相媲美，并将最先进的模型推动到新的纪录——PRIDE得分70.4，在指令生成能力上超越了最近引入的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，一个原生解耦的0.33B参数模型，对指令改写表现出近乎完美的鲁棒性。最终，我们的工作证明，通过优雅的结构设计可以实现鲁棒的语义接地，绕开低效的暴力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

## 2. 论文提出的方法论

**核心思想**

- 论文提出 **Grounded Semantic Re-binding（GSR，语义接地重绑定）**，核心思路是：绕过 VLA 架构中不稳定的"视觉-语言联合编码"路由，改为**用独立的语言编码器提取纯任务语义**，再将该语义与原生视觉特征在动作策略内部显式融合，并**完全重新初始化动作专家（action expert）从头训练**，从而修复断裂的语义传递路径。

**关键技术细节（按模型架构自适应）**

1. **稳定语义源**：使用冻结的 T5-large 编码器处理真实任务指令，提取 token 级语义表征。T5 不接收任何图像或机器人状态，确保语义完全独立于动态视觉输入。
2. **注入方式依架构而定**（架构感知指南）：
   - **VLA-Adapter**（独立动作策略）：将投影后的 T5 特征作为 "sidecar" key/value 源，注入 Bridge-Attention 的每一个 MLPResNetBlock 中；同时将原 Qwen 路径的指令替换为固定中性提示 "perform the task"，迫使模型完全依赖T5语义。
   - **SmolVLA / π0.5**（VLM 早融合架构）：将投影后的 T5 token 直接注入 VLM（SmolVLM / PaliGemma）的原生语言 token 位置，使稳定语义与视觉场景在 VLM 原生计算中深度融合。
   - **π0.5 特例**：其原生 PaliGemma 语言路径本身就稳健，故保留真实指令，T5 仅作补充语义源。
3. **动作专家重初始化**：不微调预训练权重，而是随机初始化动作专家（如 Bridge-Attention 策略、flow-matching expert），仅用标准（canonical）示范数据从头训练。
4. **ParaVLA（原生解耦架构）**：完全取消联合视觉-语言编码，用 DINOv2 处理图像、冻结 T5 处理语言，仅在最终动作专家中结合。该 0.33B 参数模型对指令改写表现出近乎完美的鲁棒性。

**关键公式或指标**

- 动作距离度量：对动作向量归一化后计算欧氏距离 D(a, b) = ‖ā − b̄‖₂
- Retrieval@1：检测释义指令产生的动作是否最接近正确标准指令的动作
- 语义保持度 R = (Δ_wrong − Δ_para) / (Δ_wrong + Δ_para)，正值表示释义响应仍比错误任务更接近正确任务

## 3. 实验设计

**数据集与基准**

- **LIBERO-Goal**：训练集，仅使用 428 集（52,042 个 transition）的标准示范数据，涵盖十个视觉环境相同的任务，迫使模型完全依赖语言来区分任务。
- **LIBERO-Para**：评估基准，共 4,092 集，在保持物理任务、初始状态和成功标准不变的前提下改写指令——包括动作改写（870 集）、物体引用改写（259 集）、两者混合改写（2,963 集）。
- **Goal-100 诊断集**：自建，10 个任务 × 10 个官方初始状态 = 100 个场景，配标准指令、人工改写指令和循环错误任务指令。
- **真实机器人实验**：4 个抓取任务 + 2 个堆叠任务，共享同一场景与四物体布局，用自然语言区分任务。

**对比方法**

- OpenVLA-OFT、SmolVLA、X-VLA、VLA-Adapter、Xiaomi-Robotics-0、π0.5（部分引用已发表结果）。
- 消融对比：原生模型、原生+T5、增加泛化参数（无语言模型）、Qwen-VL 替换 T5、不同注入点等。

**主要评估指标**

- 成功率（Goal SR / Full Para SR）、PRIDE 指标（带权重偏差的官方指标，默认 α=0.5）、性能下降幅度（Drop = Goal SR − Para SR）。

## 6. 论文的主要结论与发现

1. **VLA 释义失败根因是架构性翻译问题而非语义理解问题**：探针分析显示模型在内部保留了正确任务语义，但下游动作策略无法正确处理由释义引起的特征偏移。
2. **GSR 无需任何释义训练数据即可显著恢复鲁棒性**：
   - VLA-Adapter：46.82% → 70.94%（+44.6 个百分点的提升）
   - SmolVLA：4.47% → 49.12%
   - π0.5：73.60% → 75.59%（PRIDE 创新高 70.4）
3. **轻量模型可以比肩大规模模型**：VLA-Adapter（0.51B）+ GSR 达到 70.94% 的释义成功率，接近大规模异构预训练的 π0.5 的基线水平（73.60%）。
4. **GSR 与数据扩展正交**：即使对已被大规模数据强化的 π0.5，GSR 仍能带来进一步提升。
5. **原生解耦架构可行**：ParaVLA（0.33B）在标准指令（92.0%）和释义指令（91.0%）上几乎无性能差，说明完全分离视觉-语言编码可以根本性地解决语言污染问题。
6. **架构内部机制存在显著差异**：VLA-Adapter 中任务语义集中在最后一个 Bridge-Attention 块（单点瓶颈），而 SmolVLA 和 π0.5 的任务语义分布式地纠缠在多层。这决定了修复策略必须架构自适应。

## 7. 优点

1. **诊断方法与因果证据严谨**：不只是做数据层面的成功/失败统计，而是进行了多种因果干预（token 级替换、层级激活替换、图像替换、词向子空间移除），确凿地证明了"语义保留但翻译失败"这一核心论断。
2. **方法优雅、低成本、正交性强**：仅用标准示范数据即可修复，不依赖大规模释义数据；且对于已经被大模型/大数据强化过的 π0.5 仍然有效，说明贡献独立于数据规模。
3. **架构感知的通用方法论**：不是固定的结构补丁，而是给出了一套适应不同架构（独立策略 vs. VLM 融合）、不同语言路径能力（脆弱 vs. 可靠）的通用准则，普适性强。
4. **理论洞察驱动设计**：从"联合编码引入系统性特征偏移"的根因洞察出发，自然导出"独立提取+后期接地+重学习映射"的解决方案，论证链条清晰。
5. **新架构的验证**：ParaVLA 用原生解耦思路从根本上规避语言污染问题，提供了除"改造现有模型"之外的另一条路。
6. **真实性验证**：包含真实机器人实验，且场景设计迫使模型真正依赖语言（共享视觉场景），实验难度设置合理。

## 8. 不足与局限

1. **真实机器人实验规模较小**：仅 6 个任务、每条件 5 次试运行，统计效力有限；且 VLA-Adapter 原生模型在该设置下两个条件均为 0%（可能与任务难度或评估协议有关），GSR 的 50%/40% 虽然更好但部分任务（第 3、5、6 项）仍全部失败（0%），说明 40–50% 的水平对真实部署仍有距离。
2. **π0.5 标准匹配训练下标准成功率有小幅下降**（93.0% vs. 原生匹配对照），需要加倍训练量（GSR*）才能恢复至 96.0%。这表明动作专家重初始化对大模型有收敛成本，论文也承认未来需探索更高效的初始化策略。
3. **解耦架构（ParaVLA）扩展性受限**：作者坦诚指出，把视觉骨干升级到更大的 DINO 变体时，没有表现出 VLM 那样的规模收益，这构成纯解耦范式的重要瓶颈。
4. **对 T5 的依赖**：结论高度依赖 T5 的语义表征质量；若 T5 在处理某些领域语言或复杂指令时表现不佳，GSR 的泛化性可能受限。
5. **评估任务范围有限**：实证集中于 LIBERO 基准，领域为桌面操控；尚未在更丰富的任务类型（如移动操作、长程任务）和更多样的语言改写（如多语言、口语化表述）中验证。
6. **部分对比依赖已报告值**：如 OpenVLA-OFT、X-VLA、Xiaomi-Robotics-0 等模型的对比数据来自论文原文，而非统一复现环境下的直接对比，存在实验设置差异的风险。
7. **语言路由冲突测试中 SmolVLA 并发失效**：双路注入在 SmolVLA 上产生信号干扰（C/W 和 W/C 都不行），说明 GSR 的工程适配仍有模型特异性挑战。
