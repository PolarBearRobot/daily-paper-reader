## 摘要
视觉-语言-动作（VLA）策略的实时部署需要异步执行，即后续动作块与当前动作块的执行同时计算，这导致预测与执行错位，并表现为块间不连续。现有方法要么仅表面平滑块边界，要么需要昂贵的策略优化，要么仅前向预测本体感受状态而忽略关键视觉观测。本文提出FutureRTC，一种即插即用的自适应框架，在不修改底层策略的情况下，预测异步VLA控制的执行时观测和状态。具体而言，FutureRTC包含一个状态校正模块，用于补偿滚动前向预测与实际执行时本体感受状态之间的差异；以及一个观测预测模块，通过利用机器人运动作为显式物理先验，基于运动感知特征传输与重建，预测执行时视觉表示。此外，我们引入策略一致性损失，使从预测上下文生成的动作块与在VLA策略预期执行时输入下生成的动作块对齐。在模拟和真实环境中的大量实验表明，FutureRTC对推理延迟具有卓越的鲁棒性，从而实现更平滑的轨迹、更快的执行和一致更高的任务成功率。

## Abstract
Real-time deployment of Vision-Language-Action (VLA) policies necessitates asynchronous execution, wherein subsequent action chunks are computed concurrently with the execution of the current chunk, leading to prediction-execution misalignment and manifesting as inter-chunk discontinuities. Existing methods either superficially smooth chunk boundaries, require costly policy optimization, or exclusively forward-predict proprioceptive states yet neglect critical visual observations. In this paper, we propose \textbf{FutureRTC}, a plug-and-play adaptation framework that predicts execution-time observations and states for asynchronous VLA control without modifying the underlying policy. Specifically, FutureRTC features a state correction module to compensate for the discrepancy between rolled-forward and actual execution-time proprioceptive states and an observation prediction module that forecasts execution-time visual representations by leveraging robot motion as an explicit physical prior through motion-aware feature transport and reconstruction. Furthermore, we introduce a policy consistency loss to align the action chunks generated from predicted contexts with those produced under the expected execution-time inputs of the VLA policy. Extensive experiments across simulated and real-world environments demonstrate that FutureRTC achieves superior robustness to inference delays, resulting in smoother trajectories, faster execution, and consistently higher task success rates.

# FutureRTC 论文总结

## 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉-语言-动作（VLA）模型虽然在机器人学习领域取得显著进展，但其大规模参数量和极高的推理计算开销使其在实时建控中面临严峻挑战。为缓解推理频率与底层控制频率之间的差异，业界广泛采用"动作分块"策略——即策略单次前向生成一段时间内的动作序列，以摊销推理开销。
- **核心矛盾**：VLA 模型在增强规模性并部署于边端或远程服务器后，推理延迟（inference delay）成为实时控制的关键瓶颈。同步执行（synchronous execution）虽然能保证策略接收到最新观测，但迫使机器人进行等待，形成"走走停停"，牺牲了实时性和流畅性。
- **核心问题**：异步执行（asynchronous execution）虽能消除执行停顿，但因为下一个动作块在计算时，被用于生成动作的那组观测与本体状态在动作实际开始执行时已经"过期"，从而产生**预测-执行错位（prediction-execution misalignment）**，表现为动作块拼接处的不连续（inter-chunk discontinuities），并随延迟增大而累积错误。
- **现有方法的不足**：
  - 推理时方法（如 TE、BID、RTC）通过启发式后处理平滑块边界，但引入额外计算开销，且**并未在根源上修复错位问题**；
  - 训练时方法（如 T-RTC、REMAC 等）需要重新微调或重训底层 VLA，成本高，且同样未解决视觉观测的过时问题；
  - VLASH（最接近的工作）通过前向预测执行时的本体状态来缓解错位，但**依然依赖过期的视觉观测**——然而机器人运动过程中场景视觉同样在快速演化。
- **论文定位**：在"快、平滑、准确"三重目标之间寻求平衡——提出一种**即插即用、无需修改底层 VLA 的策略自适应框架 FutureRTC**，通过预 测执行时刻的观测与状态，从根本上消除预测-执行错位。

## 二、方法论：核心思想、关键技术细节与公式

整体结构：FutureRTC 由 **状态校正模块（SCM）** 和 **观测预测模块（OPM）** 组成，并在外层引入 **策略一致性损失**。该框架作为适配器模块插在预训练 VLA 策略的基础上，基础 VLA 在训练和推理过程中保持冻结。

### 1. 核心思想

在异步执行中，第 `m+1` 个动作块是在时间 `t+K−d` 以陈旧对 `(o_{t+K−d}, s_{t+K−d})` 为条件生成，但实际在 `t+K` 步才被拼接执行。FutureRTC 的核心思路是：在生成动作块时，先预测出一个"执行时刻等价"的观测-状态对 `(ẑ_{t+K}, ŝ_{t+K})`，让策略在推理时就仿佛在网络和场景延迟为零的情况下执行。动作块直接从第一维开始执行（`A[0:K−1]`），无需丢弃重叠动作。

### 2. 状态校正模块（SCM）

- **目的**：补偿从陈旧状态 `s_{t+K−d}` 按已提交动作前向积分到 `s_{t+K}` 时因实际执行误差导致的残余偏差。
- **前向滚动**（沿用 VLASH 思路）：

  `s̃_{t+K} = s_{t+K−d} ⊕ Σ_{i=t+K−d}^{t+K−1} a_i`

- **残差校正**：上述积分在绝对或相对位姿控制下都会累积偏差，SCM 使用一个多层感知器（MLP）预测校正残差：

  `s̃_Δ = φ_SCM(s̃_{t+K}, d/d_max)`

  最终的执行时态为：

  `ŝ_{t+K} = s̃_{t+K} ⊕ s̃_Δ`

  其中旋转使用相对旋转合成进行更新。
- **训练损失**：`L_state = ‖(s_{t+K} ⊖ s̃_{t+K}) − s̃_Δ‖²₂`，即以真实演示中的执行时状态与滚动状态之差作为监督。

### 3. 观测预测模块（OPM）

- **目的**：预测执行时的视觉观测，弥补单纯校正状态无法解决视觉信息过时的问题。
- **工作在潜在表示空间**：使用 VLA 预训练视觉编码器的特征 `z = E(o)`，避免高维像素重建，同时保证与 VLA 策略特征兼容。
- **显式运动先验**：在时间延迟窗口内的已提交动作序列 `[a_{t+K−d}, ..., a_{t+K−1}]` 直接决定了场景变化，作者将每个动作 `a_i` 映射为物理特征向量：

  `u_i = [a_i, Σ_{j≤i} a_j, a_i−a_{i−1}, Σ_{j≤i}|a_j|, id]`

  分别编码瞬时指令、累计位移、动作增量、累计路径长度、时间进度五个维度，构成轨迹特征矩阵 `U`，其后通过时间自注意力块产生动作条件运动先验 `c_motion`。
- **条件特征构建**：融合运动先验 `c_motion`、陈旧潜在特征 `z_{t+K−d}`、摄像机身份嵌入 `e_cam`、位置嵌入 `e_pos` 和校正后状态 `ŝ_{t+K}`，得到条件特征 `F`。
- **运动感知特征传输**：用级联线性+卷积层将 `F` 投影为二维流位移 `Δp` 和传输门 `α∈[0,1]`，通过可微双线性采样对陈旧特征进行空间扭曲，再按门控加权混合：

  `z_trans = (1−α)·z_{t+K−d} + α·W(z_{t+K−d}, p−Δp)`

  传输门 `α` 控制静态区域保留原特征、运动区域采用扭曲后的特征。
- **特征合成门控分支**：传输只能重排特征、不能产生新内容（如夹爪接触形变、新暴露区域）。作者引入合成残差分支，以条件特征 `F`、传输残差 `z_trans − z_{t+K−d}` 和初始观测 `z_0` 为输入，预测合成特征 `r` 和合成门 `β`：

  `{r, β} = Linear(Conv(F, z_trans−z_{t+K−d}, z_0))`

  最终执行时视觉特征：

  `ẑ_{t+K} = z_trans + β·r`

- **训练损失**：`L_obs = ‖z_{t+K} − ẑ_{t+K}‖²₂`

### 4. 策略一致性损失

- **动机**：保证预测的上下文对（`ẑ_{t+K}`, `ŝ_{t+K}`）能被冻结的策略"忠实消费"，即与策略期望的真实执行时输入分布一致。
- **公式**（使用单步流近似以避免多步流匹配的开销）：

  `L_policy = ‖π_θ(z_{t+K}, s_{t+K}) − π_θ(ẑ_{t+K}, ŝ_{t+K})‖²₂`

  其中 `π_θ(·)` 为冻结的 VLA 策略。

### 5. 总目标

`L_total = L_state + L_obs + λ·L_policy`，实验中 `λ = 10`。

## 六、主要结论与发现

1. **FutureRTC 显著优于现有方法**：在 LIBERO 上，π0.5 骨干下从 d=5 到 d=20 成功率仅下降 5.7%，SmolVLA 骨干下下降 6.4%，而 Naive Async. 分别下降 21.2% 和 14.1%。所有延迟设置下均取得最高成功率和最少执行步数。
2. **Kinetix 上的鲁棒性**：从 d=0 到 d=4 仅损失 3.0% 成功率，大幅优于所有对比方法；大延迟下需要的执行步数也更少。
3. **视觉观测的过时比状态过时更关键**：对比"只校正状态"与"只校正观测"可发现，仅校 正本体状态带来的提升有限（尤其在 π0.5 上），而校正视觉观测则恢复大部分性能损失。有效验证了视觉预测的重要性。
4. **预测-执行错位是可完全消除的**：若策略获得真实的执行时观测与状态，无论延迟多大，成功率保持不变，与无延迟执行一致——这说明异步执行本身不损失性能，关键在于恢复执行时上下文。
5. **真实场景验证有效**：FutureRTC 在三个真实双臂任务中均实现最高成功率、最少执行步数和最快执行时间，且延迟提升时性能退化最小。
6. **计算开销可控**：为 π0.5 和 SmolVLA-450M 分别仅增加 6.45M/5.19M 参数和 3.64ms/3.04ms 推理延迟，符合"即插即用"高效适配的定位。

## 七、优点与亮点

1. **问题定位精准**：明确指出"仅校正状态而忽略视觉观测"是现有工作的关键盲点，并通过消融实验和错位分析实验（附录表 3）用数据证明了这一点，论证扎实。
2. **"预测执行时上下文"的思想简洁而高效**：不修改底层策略、不需要针对延迟重新训练 VLA，通过预测使策略获得"未来视角"，从而在异步执行下仍然保持准确、平滑、快速。
3. **物理先验引入巧妙**：利用机器人运动作为显式物理先验，用"运动感知特征传输"（warping）处理机器人自身运动引起的视觉变化，用"门控合成"（synthesis）补充传输无法解释的新内容，二者协同使视觉预测在物理上具有可解释性和合理性。
4. **工程性考虑周全**：在潜在空间预测（与 VLA 特征天然兼容）、传输门/合成门的可视化分析直观（图 4）、动作块从第一维执行的拼接约定与预测对齐（附带完整分析表 3）——设计细节完整可复现。
5. **实验体系完整**：从仿真（动态任务+标准 benchmark）到真实世界，从两种骨干到三种任务，从性能到平滑性、计算开销、消融等多维度分析，证据链较为完备。
6. **即插即用的泛化性**：在 π0.5（540M 级）和 SmolVLA-450M 两种不同架构、不同规模的 VLA 上均有效，表明方法具有一定普适性。

## 八、不足与局限

1. **高度动态外部环境的适用性受限**：观测预测模块假设"机器人自身是场景变化的主要来源"，通过运动先验完成特征传输。在存在独立外部运动体（如其他人/机器人/移动物体）的场景中，性能可能显著下降。论文的 Limitations 部分也承认了这一点。
2. **策略架构的适用范围有限**：框架目前只在**流匹配型 VLA** 上验证（π0.5、SmolVLA），未验证自回归（autoregressive）或离散扩散策略（如 DiscreteRTC 场景）。观测预测在潜在空间中操作，对离散 token 型视觉特征的可迁移性待研究。
3. **真实世界实验规模有限**：仅 3 个任务、每任务 20 次试验，且都基于同一机器人本体（AgileX Cobot Magic）和单一操作类型（双臂桌面操作），未报告试验次数的方差或置信区间，统计显著性无法验证。相比模拟实验的全面性，真实实验的样本量稍显薄弱。
4. **未见跨仿真到真实的泛化（sim-to-real）**：仿真中训练好的适配器是否可直接迁移到真实环境没有验证；每个场景的适配器都是独立训练的。
5. **未对比最新的推理时方法**（如 Realtime-VLA V2 在文末有引用但未纳入实验范围），且 DiscreteRTC 未能纳入对比，使与离散扩散架构的差距缺少实证。
6. **训练成本并未完全免除**：虽然 VLA 冻结，但适配器本身仍需要针对新任务/环境收集的数据进行单独训练。若任务变化频繁，适配器训练开销累积也不可忽视。

7. **延迟上限未明确**：虽然实验覆盖 d 最大到 20（LIBERO）和 4（Kinetix），但未测试更大延迟（如 d=30 或更高）下框架的性能表现，也没有给出方法能够稳健工作的延迟上限。实际部署中网络抖动可能使延迟超过训练分布范围，此时框架的鲁棒性未知；训练与测试延迟分布不一致的泛化表现也未被分析。

## 九、总结与综合评价

FutureRTC 是一篇定位清晰、方法扎实、实验充分的机器人学习论文。它在“异步执行是提升 VLA 实时性的必然选择，但预测-执行错位是核心障碍”这一关键判断上，做出了一个简洁而有效的回答：不修改策略、不放弃异步，而是通过状态校正与潜在空间观测预测，让策略在执行时刻的上下文上做推理。相比同类工作，它最突出的贡献在于明确指出并验证了“视觉观测过时比本体状态过时更具破坏性”这一此前被忽视的洞察，并通过运动先验驱动的特征传输与合成门控机制，将视觉预测问题在物理上变得可解释、在工程上变得可行。

从学术贡献看，该工作的价值不仅在于性能上的全面领先，更在于它为 VLA 实时化部署提供了一条**无需重训、与架构解耦、可插拔**的技术路线，具有较强的实用潜力。从局限性看，其视觉预测逻辑高度依赖“场景变化主要由机器人自身运动引起”的假设，在开放动态环境中尚存明显短板；真实实验的规模与统计严谨性也仍有提升空间。总体而言，这是一篇问题意识强、技术路线优雅、实验闭环完整的高质量研究工作，对未来 VLA 机器人系统的实时部署研究具有良好参考价值。
