## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高质量全身演示的高效收集需要对移动基座和机械臂进行协调控制；在模型层面，现有的VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为应对这些挑战，我们开发了一套全身遥操作系统和一种全景感知的VLA策略。该系统通过单一VR接口实现对轮式双臂机器人的协调控制，并支持获取包含5.5小时多模态演示的真实世界移动操作数据集。在此数据集的基础上，我们提出了PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。PanoVLA基于Mixture-of-Transformers架构，通过专门的全景编码和融合模块引入全局空间上下文，能够将全景观测与语言指令和机器人状态有效集成以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA实现了平均阶段完成率91.3%和端到端成功率73.4%，大幅优于局部视角基线。这些结果表明，融入全景空间上下文能够提升移动机器人的空间理解和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 总体思路
论文提出了一套统一的移动操作学习框架，包含两大组成部分：
1. **GMR-based全身遥操作系统**：用于高效采集协调的移动+操作演示数据。
2. **PanoVLA模型**：一种全景感知的Mixture-of-Transformers VLA策略，将全景上下文注入动作生成过程。

### 2.2 遥操作系统
- **硬件架构**：操作者佩戴VR头显（6-DoF头部追踪）、双手柄（手部姿态+夹爪指令）、腰部与双脚踝共三个身体追踪器，形成稀疏动作捕获界面。
- **运动重定向**：通过实时SMPL重建提取骨盆运动、脚步运动、双手姿态，输入到GMR（General Motion Retargeting）优化框架中，生成为轮式双臂机器人（RANGER MINI 3基座 + 两个6-DoF PIPER机械臂 + 平行夹爪）的全身控制指令。

- **优化目标**：在每个控制步，机器人配置 q = (x_b, y_b, θ_b, q_L, q_R) 通过最小化加权目标获得：

  q\* = arg min_q  λ_pos L_pos + λ_rot L_rot + λ_base L_base + λ_reg L_reg

  - L_pos：手与夹爪位置对齐
  - L_rot：手与末端执行器方向对齐
  - L_base：将基座平面运动与操作者骨盆位移和朝向耦合
  - L_reg：约束关节极限并抑制过大的配置变化

- **基座建模**：将移动基座建模为3-DoF平面虚拟浮动基座，与双臂关节联合优化，使基座在目标末端位姿超出机械臂工作空间时可自动调整位置和朝向，降低重定向误差。
- **模式切换策略**：提出基于成本的动态模式切换机制，在每个控制周期评估三种运动模式（如直行、Ackermann转向、斜向平移）与期望运动之间的匹配代价，选择最优模式执行，实现基座运动对操作者意图的动态跟随。

### 2.3 PanoVLA模型架构

- **整体结构**：基于π0.5双专家backbone，扩展为三专家MoT（Mixture-of-Transformers）架构：
  1. **VLM专家**：编码局部视图（SigLIP）、语言指令和本体感受状态
  2. **全景专家**：将全景观测转换为任务条件化空间上下文
  3. **动作专家**：预测连续动作块
- **KV Cache融合机制**：采用Transformer的KV cache作为模块间融合接口。VLM专家生成VLM cache（C_vlm），全景专家联合自注意力处理全景token与VLM cache后生成全景cache（C_pano），动作专家基于拼接后的cache（[C_vlm; C_pano]）预测动作。

- **全景编码器**：
  - 先将双鱼眼图像通过球面重投影（spherical reprojection）生成等距柱状投影（ERP）全景图，形成连续、机器人中心的全景表示
  - 使用MTPano（全景基础模型）提取语义分支和深度分支的中层特征，拼接为统一的稠密全景表示
  - 通过自适应平均池化压缩为固定数量的token，再由轻量MLP映射到全景专家的隐藏维度

- **全景专家**：在block-wise causal mask下进行联合自注意力，条件化为任务相关的全局空间上下文，输出全景cache供动作专家使用。

- **训练目标**：使用条件流匹配（Conditional Flow Matching）。对于演示的动作块a、带噪样本x_τ和流匹配时间步τ，最小化：

  L = E[||v_act_θ(x_τ, τ | C_t) − u(x_τ | a)||²₂]

  其中u为目标速度场，v_act为动作专家预测的速度场。

## 3. 实验设计：数据集、Benchmark与对比方法

### 3.1 数据集
- **规模**：4个真实世界任务 × 200条成功演示轨迹 = 800条轨迹，总计约5.5小时，约500K同步帧，采样频率25Hz。
- **任务设计**（任务分类见表I）：
  - **Move Pen**：将笔放入笔筒；目标方位从前/左/右变化
  - **Move Block**：将积木移至前侧区域；目标在左/右/双侧
  - **Open Curtain**：打开两侧窗帘；需要左右顺序交互
  - **Wipe Table**：沿长桌擦除污渍并将毛巾归位；超长工作空间
- **任务设计特点**：任务相关区域不能同时被局部相机覆盖，要求跨视角空间推理与多阶段状态追踪。
- **数据模态**（每步同步记录）：局部RGB视图（前向相机+2个腕部相机）、360度全景视图（顶部相机，ERP格式）、本体感受状态（双臂关节位置、夹爪开合状态、基座平面位姿）、全身动作（17维：14维双臂+夹爪、3维基座速度指令）。

### 3.2 评估协议
- **任务分解**：每个任务分解为多个阶段，共60次闭环真实机器人测试（每方法每任务15次）。
- **指标**：
  - **成功率（SR）**：二值的轨迹级指标，全程无人工重置
  - **阶段完成率（SCR）**：所有试验中已完成阶段的平均比例

### 3.3 对比方法（受控变量设计）
- **π0.5**：仅使用局部相机视图的VLA基线
- **π0.5 w/ Pano**：将ERP全景直接作为额外图像输入，用与局部视图相同的SigLIP编码，无专门全景分支
- **π0.5 w/ Stacked Pano**：将全景重投影为3个间隔120°的透视视图并拼接，作为额外视觉输入
- **PanoVLA**：MTPano编码 + 全景专家融合

## 6. 论文的主要结论与发现

- **主结果**：PanoVLA在四个任务上均取得最优成绩，平均SCR 91.3%、SR 73.4%，大幅优于π0.5基线（58.6% SCR、30.0% SR）。
- **全景信息本身是有用的**：π0.5 w/ Pano（80.8% SCR、56.7% SR）和π0.5 w/ Stacked Pano（70.4% SCR、38.3% SR）均超过纯局部视图基线，验证了全景观测对移动操作任务的整体价值。
- **表示方式比视野范围更重要**：不同全景处理方式的性能差异显著，说明有效全景感知不仅取决于"看得更广"，更取决于全景几何的表示方式及其与策略的融合方式。
- **全景专家提供多阶段一致性**：在Wipe Table中，raw panorama基线在最后"归位毛巾"阶段严重失败（SR仅20.0%），而PanoVLA保持73.3%的该阶段完成率、46.7% SR，说明全景专家能更有效地追踪任务状态转换并保持长时程空间一致性。
- **透视重投影的权衡**：Stacked Pano在操作密集的Wipe Table上优于raw panorama（SR 40.0% vs 20.0%），但会削弱跨视角连续性，在目标搜索类任务上表现较差。
- **消融结论**：100M全景专家规模为容量与数据效率的最佳平衡点；MTPano编码器显著优于SigLIP（SCR 95.6% vs 75.6%，SR 86.7% vs 40.0%），证实面向全景几何的专用编码器对构建空间上下文至关重要。

## 7. 优点

- **统一的数据-模型闭环框架**：同时提供数据采集工具（遥操作）和策略模型（PanoVLA），形成完整的移动操作学习解决方案。
- **自然高效的全身遥操作**：GMR重定向将基座建模为虚拟浮动基座并联合优化，操作者无需独立基座控制器，即可通过自然身体运动协调基座+双臂+夹爪，显著降低演示数据的采集难度；基于成本的动态模式切换进一步提升了物理执行鲁棒性。
- **针对全景几何的专门建模**：没有简单地将全景当作普通图像处理，而是设计了三层结构（球面重投影 → MTPano多任务全景编码 → 全景专家融合），有效弥合了全景畸变与预训练透视图编码器之间的领域差异。
- **模块化架构与KV cache复用**：基于π0.5的MoT架构扩展，利用KV cache实现专家间信息传递，保持整体框架的一般性，便于对接其他VLA backbone。
- **受控变量实验设计**：三个基线仅在"全景如何表示与融合"上有差异，公平隔离出全景建模策略的贡献，结论可信度高。
- **任务设计具有区分度**：四个任务在目标方向、双边交互、空间范围上系统变化，尤其Wipe Table的多阶段长工作空间设计能有效突出不同方法在空间一致性上的差距。
